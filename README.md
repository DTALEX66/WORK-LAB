# MINIGAME

> 单人 AI 驱动的小游戏生产与变现系统（Indie AI Game Production System）

当前主线不是普通小游戏合集，而是围绕 **异常系统模拟类小游戏** 建立可复制、可换皮、可接入 IAA 广告变现的生产系统。

## 当前原型

**异常电梯控制台**

玩家扮演夜班电梯异常控制员，不是在看剧情，而是在操作一个不断出错的系统：

- 观察楼层、电梯门、电源、异常等级、乘客数量
- 执行开门、关门、上行、下行、急停、系统重启等操作
- 处理随机异常事件
- 失败后通过模拟广告复活

## 项目目标

- 用 AI + Codex + 开源 H5 Canvas 底座快速开发小游戏
- 通过微信/抖音小游戏 IAA 广告变现
- 先验证第一款原型，再沉淀可批量复制的换皮系统

## 开发原则

- 每次只做一个功能
- 先设计，后开发
- Codex 是唯一代码执行者
- 所有修改必须可回滚
- 不偏离“异常系统模拟类小游戏”主线
