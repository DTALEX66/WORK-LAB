# MINIGME / MINIGAME

第一个小游戏项目：**星尘收集者（Star Catcher）**。

一个零依赖 HTML5 Canvas 小游戏：移动飞船收集星星、躲避陨石，在 60 秒内尽量获得高分。

## 本地运行

直接用浏览器打开 `index.html`，或使用任意静态服务器：

```bash
python -m http.server 5173
```

然后访问 <http://localhost:5173>。

## 操作

- 方向键 / WASD：移动
- 鼠标 / 触控：拖动飞船
- 空格：暂停 / 继续
- R：重新开始
