## 5. 闭环定义

只有同时满足下列条件，才能标记 `WORK_LAB_PRODUCT_CONVERGED`：
- #162 或其拆分后的等价最小 PR 全部进入 main
- main exact-SHA CI 绿
- 本机 full canonical gate 绿或每个环境限定项有明确 BLOCKED/EXTERNAL 证据
- Windows Tauri/WebView2 E2E 真实通过
- Control/Observer 边界真实，不存在假写按钮
- 至少一条真实 Super Entry + 双执行器任务链完成
- 模型路由有真实 consumer 证据
- 关键 live client deploy/readback 通过
- 旧分支完成吸收/退役
- 最终主线 authority/open register 与实际状态一致

`UNIVERSAL_WORKFLOW_VERIFIED` 仍是更强标签，不与产品闭环混淆。
