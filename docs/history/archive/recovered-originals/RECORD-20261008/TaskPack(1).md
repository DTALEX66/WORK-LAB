## 权限与使用边界

本文件只有计划效力。它不授权自动安装、下载模型、付费调用、操作客户原件或修改远端仓库。读取当前项目权威材料并完成去重映射后，才可将用户明确批准的任务转为执行。所有数字门槛均为本包建议，不能当成既有实测结果。

## WL-R00｜只读对照现有治理与权威任务

**高｜未执行｜只读准备**

目标：确认 WORK-LAB 已有治理边界、账本、适配器、恢复和审计，避免再造同类系统。

依赖：无。候选：治理与边界规则。来源：U02、U03。

### 执行步骤

1. 读取当前权威计划、实际模块、测试、锁文件和运行产物；记录项目与分支身份。
2. 登记现有 Work Unit、运行状态、事件、权限、执行器与知识引用的唯一归属。
3. 确认工具链和缓存的外置位置；无法访问编译器或权限不足时记录真实阻塞，不在仓库内偷偷安装替代环境。
4. 把本包任务映射到已有任务：已有则补证据、已完成则不重开、冲突则待项目裁决。

### 交付物

- 治理能力与代码定位表
- 依赖及环境清单
- 既有任务去重和冲突表

### 验收条件

- WORK-LAB 仍是调度治理层，不升级为第二通用运行时或专业知识库。
- 每个拟改动指向现有模块或有证据的缺口。

### 停止与回滚
项目身份或单一真值不清时不改动；不以本包覆盖当前权威任务。

资源：默认零新增付费；任何模型调用、下载大模型、外部写入或新增托管开销均需事前许可。


## WL-R01｜维护雷达候选、历史差分与证据账本

**高｜未执行｜候选治理**

目标：把本包作为 Radar 研究配置的一次可追溯候选快照，不创立第四项目或另一个业务真值库。

依赖：WL-R00。候选：治理与边界规则。来源：U01、U02。

### 执行步骤

1. 先查找已有 Radar 导入与存储；复用现有结构，必要时只做可逆字段映射。
2. 以论文标识、规范 URI、仓库归属及模型标识去重；官网、论文、模型卡和镜像合并证据组。
3. 记录旧结论、新结论、原因、版本、来源时间和核验时间；候选获批与否另列。
4. 导入仅保存研究候选与推荐，不写项目完成状态；未来导入同包应幂等。
5. 以本包数据测试提醒条件、中文输出和未覆盖提示；不自动安装、下载模型或修改 TaskPack。

### 交付物

- 候选导入映射或经授权的导入器
- 版本差分与提醒样例
- 重复导入测试

### 验收条件

- 11 个候选不会因多来源或二次导入倍增。
- 35 个来源记录与候选引用可追溯；旧评估保留。
- 未满足提醒阈值不产生新执行任务；未覆盖也不冒充无重要更新。

### 停止与回滚
发现 Radar 存储正复制业务真值时停止；撤销本次候选导入批次，不删除其他历史。

资源：默认零新增付费；任何模型调用、下载大模型、外部写入或新增托管开销均需事前许可。


## WL-R02｜MCP、ACP、AG-UI 依赖与能力兼容核查

**高｜未执行｜兼容性核查**

目标：先确定是否使用相关依赖，再对具体破坏性变更创建最小迁移工作。

依赖：WL-R00。候选：R07、R08。来源：S16、S17、S24、S32。

### 执行步骤

1. 读取锁文件和实际调用路径，区分 MCP 规范、SDK、ACP 适配器、AG-UI 子包和宿主版本。
2. 按《标准协议基线》检查 AG-UI MCP 中间件对等依赖、源策略及 Strands 的鉴权、恢复和终态变化。
3. 逐适配器列出加载、分叉、异步工具、取消、权限和历史分页能力；没有实现的能力返回明确不支持。
4. 列出受影响调用与回归样例；未使用相关包时只更新观察记录，不盲目安装。

### 交付物

- 实际依赖版本与调用路径矩阵
- 条件性迁移清单
- 能力协商与降级样例

### 验收条件

- 每项风险能指向具体包、版本及使用方式。
- 不将 codex-acp 实现版本写为 ACP 协议版本。
- 不将协议传输无状态解释为删除业务检查点。

### 停止与回滚
未发现实际依赖时结束迁移分支；出现升级回归时回退锁文件及适配配置，不回滚用户业务数据。

资源：默认零新增付费；任何模型调用、下载大模型、外部写入或新增托管开销均需事前许可。


## WL-R03｜运行状态四组对照验证

**高｜未执行｜有条件验证**

目标：判断结构化状态的收益来自哪里，只在优于简单方案或具必要审计价值时吸收。

依赖：WL-R00。候选：R05。来源：S06、S07、S08。

### 执行步骤

1. 定位现有账本和运行状态；有权威事件源时不增加平行真值。
2. 冻结现有机制、暂存笔记、确定性轻量状态、tracelab 四组配置；保持模型、输入与预算可比较。
3. 覆盖长顺序任务、顺序敏感任务、历史压缩、工具错误、重试和观察查询；不要只复跑作者优势样本。
4. 记录完成准确率、输入 Token、总费用、重放一致性、恢复与观察问答指标。
5. 将低价简单方案与结构化方案的可审计性价值分别说明；无净收益则保留现有方案。

### 交付物

- 四组实验配置与原始轨迹
- 成本与正确性对照报告
- 最小吸收或不接入决策

### 验收条件

- 便宜基线没有被故意弱化，失败样本不丢弃。
- 每一项结果均有运行标识、配置、轨迹和统计口径。
- 没有把作者报告数字写成本项目成绩。

### 停止与回滚
试验数据或设备不可用时只交设计不标通过；任何新状态存储导致双重真值时撤销该分支。

资源：默认零新增付费；任何模型调用、下载大模型、外部写入或新增托管开销均需事前许可。


## WL-R04｜工具审计、外部写入和凭据隔离

**高｜未执行｜有条件验证**

目标：以 GitHub 治理模式和 Deep Agents 修复作为测试供体，补当前项目有证据的安全边界。

依赖：WL-R00。候选：R06、R09。来源：S13、S14、S15、S18。

### 执行步骤

1. 对照现有工具调用事件，至少映射运行/工具调用标识、主体、权限上下文、目标、时序、结果与脱敏输入摘要。
2. 隔离工作区允许受控产物写入；外部仓库、共享文件、发布与部署经独立许可通道。
3. 设计假工具和假凭据测试：日志、dotenv、Git 配置、进程参数与错误信息不泄露秘密；第三方执行器也受限。
4. 对云端工作流只读分析；若后续明确授权试跑，固定 Action 提交与最小权限，并保留外部动作幂等标识。

### 交付物

- 现有治理差距与最小补丁清单
- 凭据与越权回归用例
- 外部写入确认及幂等记录模板

### 验收条件

- 拒绝的外部写入没有副作用，授权不能由模型自签。
- 测试用秘密标记不出现在日志或产物中。
- 工具失败、取消和重试都有审计终态；未实测则不能宣称安全通过。

### 停止与回滚
凭据泄露或未授权外部副作用出现时停止该提供方、隔离日志并按现有安全流程撤销凭据；不执行未知清理命令。

资源：默认零新增付费；任何模型调用、下载大模型、外部写入或新增托管开销均需事前许可。


## WL-R05｜并发记忆、检查点与中断恢复回归

**高｜未执行｜有条件验证**

目标：验证重复事件、并发追加、部分失败和恢复不会覆盖历史或重复提交外部动作。

依赖：WL-R00。候选：R05、R06、R09。来源：S06、S13、S18。

### 执行步骤

1. 复用现有事件标识、状态版本和检查点；明确幂等键、去重范围及事件顺序。
2. 用本地假工具模拟并发追加、重复投递、部分写入、提交前后断开和授权过期。
3. 恢复时重建任务状态、未完成工具与资产引用；外部结果未知必须查验，不能盲目重试。
4. 并发知识引用不复制为 WORK-LAB 专业知识；运行记忆合并保留所有有效事件及来源。

### 交付物

- 故障注入场景与日志
- 状态重放哈希记录
- 恢复与外部动作去重报告

### 验收条件

- 固定测试数据的重放状态一致。
- 并发有效记录不丢失，重复事件无重复外部副作用。
- 权限过期不能因恢复自动重获授权。

### 停止与回滚
无法回收进程树或平台拒绝操作时明确记录未验收，不绕过系统限制；停用实验执行器并保留检查点。

资源：默认零新增付费；任何模型调用、下载大模型、外部写入或新增托管开销均需事前许可。


## WL-R06｜会话适配的加载、取消与权限闭环

**高｜未执行｜有条件验证**

目标：把协议支持变成逐提供方可核验能力，不承诺跨任意运行时搬运会话。

依赖：WL-R02。候选：R07、R08。来源：S16、S17、S32。

### 执行步骤

1. 使用隔离会话验证创建、加载、分页、分叉和后台工具；保存源运行时、目标运行时及协商能力。
2. 验证取消到服务器和执行器的传播、工具子进程处置、用量终态；后端不能停时明确标记部分取消。
3. 在拒绝、批准、超时、用户断开、重复恢复和并发同线程请求下检查权限与最终状态。
4. 运行时不兼容时只允许有损上下文导出并列损失表，不伪装完整恢复。

### 交付物

- 逐适配器会话能力矩阵
- 取消与权限端到端测试报告
- 不支持与有损迁移说明

### 验收条件

- 会话分叉不继承超过明确授权范围的权限。
- 取消成功要由后端结果确认，不能仅凭界面停止动画。
- 不同适配器的终态和用量保留来源版本且可回溯。

### 停止与回滚
无法确认后端停止时不再启动替代执行；显示残留风险并交现有运维处置，不误报完成。

资源：默认零新增付费；任何模型调用、下载大模型、外部写入或新增托管开销均需事前许可。


## WL-R07｜跟踪、用量与成本的版本化映射

**中｜未执行｜有条件验证**

目标：用现有事件模型连接外部可观测性语义，而不是为新 SDK 改写内部真值。

依赖：WL-R00。候选：R09。来源：S18、S27、S28、S31。

### 执行步骤

1. 检查已有跟踪与成本记录；以运行、调用、提供方和模型为关联键，费用币种与价格时间单列。
2. 将输入、输出、缓存、嵌套模型用量与未知用量分开；无法计费时标未知，不当作零。
3. 为 OpenTelemetry/OpenInference 记录所用包、字段版本和稳定性，按适配层输出。
4. 权限上下文保留脱敏指纹或引用，不能将密钥、原始私密资料完整上送跟踪系统。

### 交付物

- 内部事件到外部语义的映射表
- 嵌套用量与未知费用测试
- 脱敏与导出禁用开关

### 验收条件

- 不同模型价格不串用；总成本可对账。
- 未知用量或缺价格不能产生伪零成本。
- 禁用外部跟踪时本地执行与审计仍能继续。

### 停止与回滚
外部跟踪权限或数据驻留要求不清时保持本地；回退适配输出而非删除原账本。

资源：默认零新增付费；任何模型调用、下载大模型、外部写入或新增托管开销均需事前许可。


## WL-R08｜候选晋级、回滚与独立验收

**高｜未执行｜验收治理**

目标：把候选→验证→正式任务→接入的每一步留痕，避免再次停在“登记了但没吸收”或无证据宣告完成。

依赖：WL-R00。候选：治理与边界规则。来源：U01、U02、U03。

### 执行步骤

1. 复用项目既有门禁；为每个候选标记待核验、待验证、验证通过、验证失败或暂缓及理由。
2. 正式接入至少附固定版本、许可证、复现结果、失败边界、提供方开关和回滚方式。
3. 执行者提交证据，独立审阅者判断；没有独立审阅条件就保留待验收，不自签。
4. 只有被选中的候选进入既有权威 TaskPack；本包不自动覆盖其他计划。

### 交付物

- 候选晋级记录模板
- 正式接入变更单模板
- 独立验收与回滚记录

### 验收条件

- 有明确淘汰或暂缓出口，不为任务数强行接入。
- 每个完成结论能定位真实运行证据而不是说明文档。
- 审计者身份、结论与执行者区分；未验证项目不记已落地。

### 停止与回滚
任何结论缺版本、许可或复现证据都不晋级；不阻塞其他已具资格且独立的任务。

资源：默认零新增付费；任何模型调用、下载大模型、外部写入或新增托管开销均需事前许可。
