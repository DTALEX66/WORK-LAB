# WORK-LAB UI 前端更新任务书

日期：2026-10-09，Asia/Shanghai。目标：DTALEX66/WORK-LAB。性质：本对话最终任务包的前端实施子包，不替代既有权威入口。

## 1. 更新目标

将前端组织为软件中立、本地优先的 AI 工作观测与配置治理工作台。外部 AI 软件执行业务项目；WORK-LAB 默认按项目观察活动、参与软件、阻碍和资源，评价与适配可复用能力，管理获准维护的规则、配置和能力版本。

同步更新页面、读模型、默认采集、导航、命令搜索、深链、测试和文档投影。只减少菜单、只换标题或只贴新效果图不算完成。

## 2. 结构与范围

推荐主要目的地为项目监控、软件与环境、能力资产、用量与缓存、规则与适配。设置保留低频入口。该数量是本轮设计建议，不作为永久测试断言。

项目/问题/能力详情中放协作摘要：经验候选、真实接收、教学引用、技术校验、反馈。AAOS拥有完整知识生命周期、人的知识工作与学习、AI学习资产和人机双向学习；DESIGN-LAB拥有专业设计、原生作品、专业接受和设计专用执行内核。三方各自独立，按需互补。

本方不新建学习中心、课件中心、知识主库或三方总审批页。联合教学可以长期保留，但不阻塞本方监控与能力适配的独立验收和发布。

旧任务、执行和证据深链保持原身份、来源、权限与错误解释。旧画布与未接通运行器可作为实验或参考资产保留，不因此成为首版义务。

## 3. 必须实现的用户行为

1. 同一项目展示参与软件集合，支持同时运行、等待或受阻；项目身份支持非Git、多目录、worktree与同名项目。工作、健康、观测三个状态轴分开。
2. 显示最新可见来源和时间。断连不判软件停止，无日志不判失败，turn_end不判项目完成。事后导出的数据不能称实时。
3. 能力流程包含源评价、许可/依赖/权限、目标选择、差异与损失、隔离试用、目标验证、受管部署和恢复；源验证不替代目标验证。
4. Token、Credits、额度、费用和机器资源分别呈现。缺失、实报零和不可计算分开；保留精确子集、估算子集与未知。未知全局分母不展示虚构覆盖率。
5. 缓存输入占比按完整同口径输入子集加权；命中率按可判断请求计算。缓存写入不算命中，不平均会话百分比。
6. 规则意图、投影、写入、原生加载、行为验证分别记录。保护用户编辑，三方比较前态、本方发布态与原生现态；恢复仅触及本次范围。
7. Observer允许搜索、筛选、复制与展开；业务写操作采用独立受管命令，由服务端核对真实授权、范围、前态、版本与幂等身份。
8. 默认不采集私人正文、工具载荷和人的完整学习回答。按需诊断限定项目、问题、时间与保留范围。同步后台，不能只隐藏UI。
9. 无数据、未连接、不支持、隐私隐藏、延迟、局部故障、权限不足和对象不存在分别解释。单适配器故障不抹掉其他来源或历史记录。
10. 搜索、选择和阅读位置稳定；新事件不抢焦点；暂停滚动、停止采集、退出窗口和停止原生软件分开。

## 5. 视觉实施

使用本包16张母版和浅深主题对照内容层级、密度与状态。文字、表格、数值、图表与交互控件使用真实组件；SVG图标可直接复用。母版是本次设计建议，不能反向删掉仓库仍有效的功能或权威规则。

优先保留React/TypeScript/Vite、Tauri/Rust、Python分工和已工作的组件/主题。不得因为本包附静态HTML参考，就将现有产品换成固定坐标网页或全量换栈。具体样式适配以已有品牌及可访问性为准。

修订历史“必须7组/旧页全入导航”等过时断言，保留稳定身份、可达性、正确权限、无重复ID与深链行为。不能删测试或skip来变绿，也不能换成永久“必须5组”。
