# 路由、权威与历史迁移

原23条路由建议完整保存在`inputs/frontend_route_mapping.proposed.csv`，这是种子表，不是已迁移事实。发现当前registry后逐项登记旧ID、对象参数、可见性、消费者、真实新位置、兼容策略与验证证据。设计页ID不能直接当生产路由替代旧ID。

| 旧入口类别 | 处理方式 |
|---|---|
| overview / projects | 合并日用首页语义，保留projectId与既有深链 |
| agents / software / monitoring | 软件视角、资格和采集健康合并，避免另一总览 |
| tools / workflows | 能力来源、评价、迁移与有效模板；不承诺完整运行器 |
| rules-policy / integrations / approvals | 规则、连接与限定对象授权，不设三方上级审批 |
| models | 用量视角归用量，连接配置归规则，避免另一个模型平台 |
| work / executions / execution-detail / evidence / delivery | 兼容只读详情或限定诊断，保持对象和接受状态 |
| memory | 获准AAOS连接/版本解释，不建本地知识主库 |
| audit / trust / observer | 对象历史、质量与诊断，消除重复日用入口 |
| task-packs | 本仓工程诊断，不要求所有被观察项目登记任务 |
| workflow-editor | 退出默认导航，保留有效实验实现与未接通说明 |
| settings | 低频设置，隐私/外观/存储/连接，避免复制业务页 |

保留URL参数的语义与命名空间。不能旧链接没找到就静默展示最新execution，也不能将同名另一个项目当恢复成功。兼容入口只读且按权限校验；迁移后可恢复原对象或给出明确缺失/归档状态。

更新范围包括App、viewRegistry、Sidebar、命令搜索、deep links、页面标题/副标题、默认选项、读模型、采集默认与测试。测试保留必要入口可达、无重复ID、对象稳定、权限正确；定向更新旧数字断言，不删除安全测试。

权威体系继续使用既有WORK-LAB-AUTHORITY、两个索引、CURRENT、OPEN、边界与所有权合同。修定义务与当前任务继承关系；README是摘要，AGENTS是本仓开发入口，不对所有外部项目施加本仓任务流程。

现行规范、未来规划、历史证据、生成投影各有角色和适用性；能力实现状态另记录。历史COMPLETE/FINAL不自动授权。未来/延后不算完成，历史失败证据和未结缺陷不清零。

归档先找反向消费者并迁移，再做可恢复保留点、位置与索引更新、从源再生和验证。签名/哈希绑定原件不改字节；旁置更正。历史AGENTS/CLAUDE/SKILL需验证自动发现，必要时非自动加载封装。允许现行文档引用历史证据，禁止借旧指令恢复被替代义务。

已部署客户端投影、其他worktree、Project附件和旧下载包按来源与权限定向更新。未访问记未核对；本仓变更不自动清理外部副本。本UI包也必须登记其执行输入角色，不能直接放进全局自动加载目录产生另一权威。
