# 素材生成与补齐提示词

当前32张桌面4K图、SVG母版、24枚图标和61张切片已能支持本轮前端对照开发。优先使用源码/矢量，不重新生成已有按钮、文字、数据表和图表。没有必须额外补齐的照片或样机。

## 精确放大或局部调整

优先给Agent这段：

> 读取design/scenes和tools/build_ui.py对应页面。修改唯一生成源的相关组件，再按目标分辨率直接重绘；中文、数值、状态、对象身份、布局位置必须保持。需要局部资产时按slice_manifest的逻辑rect提取，保留透明背景或原主题背景，不从截图猜坐标。整页或动态文字不得烧成生产UI位图。

## 栅格装饰确需生成时

仅在真实品牌资产缺失或用户明确新增装饰需求时使用图像生成，并提供已确认参考。不要将生成图冒充正式LOGO。可用提示词：

> 为WORK-LAB专业本地工作观测台制作一张独立、无文字、无数值、无按钮、无品牌标志的极简辅助装饰。深蓝黑底#0B1018，细微蓝线#62A8FF，体现多软件围绕项目协作与能力适配。低对比、低噪声，不发光、不做宇宙星空，不新增复杂控制器或学习平台意象。布局和比例以提供的region为准；如果作为叠加图标或装饰，输出透明背景。真实界面文字与状态由代码叠加。

## 正式品牌与官方软件标志

先在仓库及用户已有VI中查找获准文件，核对最新版本/许可/用途；保留矢量源和命名。旧副标题“EXECUTION CONTROL PLANE”不再自动代表当前产品定位。没有确认的官方软件LOGO时使用中立图标与准确软件名称，不生成仿官方标志。

## 交付要求

每个补齐资产登记ID、来源、生成/修改方法、用途、尺寸、主题、许可或授权状态、原件摘要与部署位置。素材生成成功不能记为产品接入、技术验收、用户接受或发布完成。
