## 设计边界

项目监控作为首页；软件接入、能力评价与迁移、用量缓存、规则适配保留主要入口。协作摘要进入相关对象详情。旧任务/执行/证据入口保留身份与只读兼容；实验编排退出默认导航。

所有页面使用明确标注的合成演示数据。没有 AAOS 真实接收、DESIGN-LAB 真实工件、真人学习、Windows 安装验收或生产部署。源文件中的历史提交身份不代表当前远端状态。

生产部署使用真实组件与数据合同。整页截图和包含动态文字的切片用于比对；图标可以复用。不要把整页PNG贴作真实前端，也不要让演示数字进入生产默认数据。

文字转曲SVG最适合无损放大；文字可编辑SVG依赖本机字体。原型是设计导航参考，固定坐标母版缩放不等同生产响应式实现。Windows中文输入、DPI、原生壳、读写权限与真实接口需按验收清单测试。

本轮未重新取得用户最新确认的完整VI母版。排版保留WORK-LAB名称及蓝色专业工作台方向，未宣布更换正式LOGO。实施时优先复用仓库现有已确认标志、组件、字体与主题；不要重新部署旧的“EXECUTION CONTROL PLANE”定位副标题。
