## 读取优先级与范围

最终任务书汇总后续用户澄清：项目级监控、能力评价与迁移、AAOS完整知识学习定位、DESIGN-LAB专业内核、三方按需互补、权威/前端/历史整体对齐。早期逐请求日用监控等提案在原文件保留，已替代部分不能继续派工。五目的地是建议，不是永久数字约束。

三套原资料及全部压缩成员均保留；原实验哈希、失败和旧运行没有改写。证据中的源码SHA是当时开发分支，不是main部署或用户本机事实。包内历史build_packet.py仅作原件；复跑使用下述限定脚本，不要求重新构建旧资料。

覆盖范围为本线程可见内容与本对话已取得三个资料包。早期逐字聊天全文未能独立取回，不能声称附有不可见的完整聊天导出；其已形成的报告和证据完整保存。无需把这个限制误写成产品任务缺失或已实现。

## 可复跑材料

解压后，用现有Python在对应目录运行；无需联网、安装或访问仓库/客户端：

```text
python source_packets/research/reproduce_usage_quality.py
python source_packets/collaboration/run_local_audit.py
```

第一个只输出两个合成计量反例，函数体为历史行为最小复制，不是导入现行仓库。第二个先核对三个冻结源码blob，创建新的runs目录，不改冻结原件/历史运行。S1/S2预期不满足内容要求，S3预期技术通过，全部真人接受未执行。复现历史缺陷成功不代表缺陷修复；内存候选通过不代表落仓/持久Outbox/在线接收。

本轮复跑结果另存 `verification/`；其环境是本次Linux/Python，不能替代Windows、完整CI、AAOS/DESIGN-LAB、真人学习或效果测量。候选默认出域拒绝，未发送，补丁未应用到仓库。

## 使用方式

把整个解压目录与当前WORK-LAB检出一起交给执行Agent，使用02正文。先核对当前现场和既有授权，再沿既有CURRENT/OPEN整合，不把本包并入自动加载路径作为第二规范。无需等待B4联合教学完成才验收独立监控/能力迁移。

原件不直接改；更正与替代旁置。新增规划不算实现，任务延后不算完成，失败证据不清零。执行结束必须返回实际差异、范围扫描、路由/任务/文件处置、真实测试/读回、冷启动与恢复点，另列未实现/未验/未接入/未发布。
