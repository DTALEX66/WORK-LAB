# 素材、切片与部署

## 取用顺序

先读页面清单，再查看4K图；需要精确放大时用转曲SVG，需要改文字时改scene JSON/生成源码或文字SVG。切片用于局部比对，索引记录源页面、逻辑rect、渲染比例、像素rect与用途。

逻辑母版1600×900，4K比例2.4，1440p比例1.6。切片由4K原图按逻辑坐标乘比例直接裁出。窄屏逻辑768×1200、高清比例2，输出1536×2400。改变布局应重绘场景，不裁掉侧栏冒充响应式。

## 资产分类

| 内容 | 可部署方式 | 注意 |
|---|---|---|
| assets/icons/*.svg | 作为SVG组件/icon sprite；currentColor驱动主题 | 24枚原创线性图标，统一viewBox与描边 |
| 整页PNG / 内容切片 | 设计比对、审阅、回归参考 | 不作为整页背景或动态按钮/文字 |
| design/svg/*.svg | 设计工具导入，无损放大，适合切片定位 | 文字转曲；真实UI用语义组件 |
| design/svg_text/*.svg | 编辑文字和形状 | 本机字体可能改变字宽；精确视觉对照转曲版 |
| design/scenes/*.json | 修改内容、坐标、颜色后重绘 | 原始文字与操作保留，schema是设计场景格式 |
| prototype/ | 本地参考浏览 | 原型不是生产React/Tauri实现，没有真实接口 |
| assets/fonts/ | 参考原型拉丁字形，附DejaVu许可 | 生产沿用已确认字体；中文使用系统字体 |

无需额外生成照片、样机或AI背景。WORK-LAB是数据工作台，现有母版所需装饰、图标与线条已交付。若真实品牌母版、第三方图标或软件LOGO需要补齐，先检查仓库/已有包/许可；不能用生成图伪装官方标志。

## Agent对照开发

1. 找到页面对应ID与主面板region。
2. 从scene读取标题、文本、状态、布局坐标和颜色，用既有组件实现。
3. 将示例读模型映射真实合同；无来源时用正确空态，不回填演示数据。
4. 用SVG图标，动态表格/徽章/图表用组件与实际字段。
5. 在相同视口截取真实前端，核对间距、行高、信息层级、状态和错误路径。
6. 视觉差异不能通过减少有效字段、藏错、删权限检查或截断正文消除。

切片清单中`use=visual_reference`是参考资产，不是指令授权或生产数据。建议用户本地解压到`D:/All projects/UI套件/WORK-LAB_UI_20261009/`；该路径是交接建议，本轮未写入Windows设备。

## 重绘

已有图可直接使用。可选重绘依赖Python、Pillow、fontTools、PyMuPDF；脚本离线读取运行时CJK字形并使用已附DejaVu字体，无需调用模型。

```text
python tools/build_ui.py
python tools/validate_package.py
```

PNG从矢量场景坐标直接按目标分辨率绘制，4K不是小图插值放大。修改scene文本需同步生成源码；当前工具以build_ui.py为生成源，scenes是可读可编辑投影，不能只改投影后期望下一次生成保留。若增加JSON读取模式，先指定唯一源并记录迁移。
