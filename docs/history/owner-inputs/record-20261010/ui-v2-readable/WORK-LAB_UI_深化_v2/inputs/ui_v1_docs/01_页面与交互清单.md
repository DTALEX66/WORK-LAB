# 页面与交互

16张桌面母版均有浅深主题。每张页面有4K、1440p、转曲SVG、文字SVG与场景JSON。下列ID是设计工件ID，不预设生产路由。

| 设计ID | 页面 | 用户行为与必需数据 | 主要去向 |
|---|---|---|---|
| 01_projects | 项目监控 | 项目集合、软件集合、三轴、新鲜度、主要阻碍、已知用量；筛选和选择不触发业务任务 | 项目详情、来源详情、能力、规则 |
| 02_project_detail | 项目详情 | 固定projectId、目录/worktree归属、参与软件、用量质量、协作摘要 | 限定诊断、协作详情 |
| 03_software | 软件与环境 | software/version/surface/鉴权/适配器/字段资格、参与项目、更新退化 | 软件详情、接入向导 |
| 04_software_detail | 软件详情 | 字段支持范围、源时间、接收时间、last-good、参与项目与缺口 | 项目、限定诊断 |
| 05_assets | 能力资产 | 原创/收藏/第三方来源，Skill/MCP/Hook等类型，源评价、迁移状态 | 能力详情 |
| 06_asset_detail | 能力详情 | 来源身份、版本、许可、依赖、适用条件、失败反例、用户判断、目标选择 | 差异预览 |
| 07_migration | 能力迁移差异 | 源/目标/适配器版本，路径映射、损失、试用、验证、部署条件与恢复 | 限定试用与受管命令 |
| 08_usage | 用量与缓存 | 单位/作用域/质量、精确与估算子集、未归属、缓存分母与口径 | 按项目/软件筛选、质量说明 |
| 09_rules | 规则与适配 | 规则意图、原生投影、写入/加载/验证、漂移、获准连接 | 差异、协作连接 |
| 10_rule_diff | 用户编辑冲突 | 前态/发布态/原生现态、目标与摘要、最小差异、恢复条件 | 保留现态、限定合并方案 |
| 11_collaboration | 对象协作详情 | 本方候选、真实对端回执、教学版本、技术校验、最小反馈、责任归属 | 各方已有授权链接 |
| 12_diagnostics | 按需诊断/历史 | 原对象身份、项目/问题/时间、授权、证据质量、缺口与接受 | 复制、只读查看、范围说明 |
| 13_settings | 设置与隐私 | 最小采集、保留、诊断范围、主题、减动、窗口/采集分离 | 低频设置与说明 |
| 14_states | 状态组件规范 | 无数据、未连接、不支持、隐私隐藏、延迟、局部故障、值状态 | 开发与空态对照 |
| 15_first_run | 首次接入 | 已授权发现、资格与字段、差异、低风险真实活动、回读 | 按资格逐阶段判断 |
| 16_components | 组件规范 | 按钮/徽章/指标/摘要/导航/图标/密度/可访问性 | 开发参考 |
| 17_mobile | 窄屏读取 | 项目摘要优先；复杂差异回到可读桌面布局 | 同对象详情，不能错身份 |

## 交互要求

全局搜索仅检索有权限对象；命令搜索中的观察与写操作分别标识。搜索和筛选不等于请求更多源端采集。选择项、排序、展开和阅读位置在新事件出现时保持；用户明确切换过滤条件后再调整。

详情按完整命名空间身份读取，不能凭名称替代。项目同名、多目录与多worktree共享/独立归属需读模型事实。未归属用量仍进入守恒总量，不强行绑定最像的项目。

每个图表可查看来源、时间区间、单位与数据质量。没有真实历史序列时不画虚构趋势；生产空态不能沿用本包的合成柱图。源端只支持事后导出时展示“事后可见”。

配置或资产命令先预览实际目标、差异和条件；服务端返回事实结果后分别更新写入、原生加载、行为验证。条件缺失时显示具体原因与可行下一步，不只灰掉按钮。低风险已授权动作按实际策略执行，不额外创建总人审流程。

## 状态表达

工作：运行、等待输入、受阻、本轮结束、未知。健康：正常、重试、疑似停滞、故障、未知。观测：连通、延迟、断连、有限、仅历史、不支持、未接入。具体值应映射现有合同，这里是展示语义。

不能把三个轴合并成一个绿点。“技术通过”“专业接受”“人的学习评价”“发布”也分别标注；候选本地生成不显示对端已收到。

空态和异常的可行操作：无数据可改时间范围；未连接进入资格/接入说明；不支持列字段限制；隐私隐藏解释当前策略；延迟保留last-good；局部故障只处理该适配器；权限不足说明所需范围；缺失对象保留原ID并提供返回路径。

## 参考原型范围

原型有真实的本地页面导航、主题切换、设计页搜索和条件说明对话框，剪贴板可用时复制当前演示对象ID。没有监控、API、受管命令或真实过滤后的数据。

DESIGN-LAB与AAOS选择保留原对象身份并提示母版范围，不跳成WORK-LAB详情。部署时用同一详情组件读取真实projectId。固定坐标缩放是设计浏览方式，不是完成生产响应式的证据。
