基于专业紧凑工作台：深蓝黑底、细边框、蓝色交互、低噪声状态色；不加宇宙背景、全屏光效或强发光。项目状态与密集信息保持可读。浅色主题同步层级与语义。

本包是本轮视觉建议，优先适配仓库已有主题与正式VI。LOGO未重新定版，首页排版仅保留名称。字体在生产优先沿用已有Inter/Segoe UI/中文系统字体；原始效果图使用DejaVu与运行时Droid字形渲染，文字转曲SVG保留精确视觉。正文不使用图片文字。

## 密度与结构

1600×900逻辑母版；桌面矢量直接渲染为3840×2160及2560×1440。推荐侧栏222逻辑px、顶栏63px、主区横向起点254px、卡片间距18–20px。8px间距基础，卡片圆角8–9px、按钮6px、徽章5px。边线1px，图标1.6px描边，统一24×24 viewBox。

标题27px、卡片标题16px、正文12–14px、说明11–12px、元信息10–11px、指标28px。生产在高DPI/字体缩放下验证，不能为了塞更多文字低于用户可读尺寸。需要扩大字号时允许内容重排和滚动。

## 组件

| 组件 | 必需状态 | 内容与行为 |
|---|---|---|
| ProjectSummary / Participants | 多软件、混合三轴、部分观测、未归属 | 项目身份稳定，进入同对象详情 |
| MetricWithQuality | 实报值/零、未知、隐藏、不可计算、混合精度 | 单位、范围、分母与质量解释 |

| LegacyReadOnly | 对象存在/缺失/权限不足/已归档 | 原身份与解释不丢 |

## 自适应与可访问性

生产桌面≥1440时保留双列/矩阵；1024–1439时侧栏可缩到图标栏，主区优先单列；768–1023优先项目摘要与横向可滚矩阵；<768优先卡片读取，复杂差异分段或提供桌面模式。断点是建议，不是测试只看这几个宽度。

大于100%字体/DPI时不要依赖固定高度截断正文。长路径、长软件名、双语、长状态、错误详情分别用可访问省略/展开或换行。矩阵必须有可读列标题与可聚焦横向滚动区。

Tab顺序按导航→筛选→内容→操作；焦点明确可见，Esc关闭弹窗后回到触发点；全局搜索支持Ctrl/Cmd K，中文IME组合阶段不误触快捷键。状态同时用文字，不只用颜色。更新摘要限频播报，不逐条抢焦点。减动模式关闭非必要动画；普通悬停约120ms，不使用持续闪烁。

颜色对比、键盘、屏幕阅读器、中文字体与DPI均需生产环境实测。当前包只完成视觉检查与静态验证，未将这些写成已通过。
