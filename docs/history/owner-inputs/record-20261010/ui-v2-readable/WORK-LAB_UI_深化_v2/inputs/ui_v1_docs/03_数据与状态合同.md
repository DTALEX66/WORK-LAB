# 前端读模型与状态合同

`contracts/ui_read_model.ts`是UI所需语义示意，不是另一个后端Schema。映射已有接口、provider字段、缓存定义和权限模型；不足时最小兼容扩展，不能复制成第二计量真源。演示fixture不得进入生产默认状态。

## 身份、时间与观察

projectId、softwareInstallationId、runtimeInstanceId、sessionId按来源命名空间分开。项目名称/remote/PID不足以唯一确认身份。参与软件集合来自已授权读模型；一次事件可以关联多个对象，但计费贡献只计一次。

区分event_at、source_emitted_at、received_at与visible_at，优先真实源序列和因果身份；无序列/时钟不可靠时标限制。latestVisible状态是最后可见快照，不等于当前原生真实状态。断连、滞后或窗口关闭不推出软件停止。

## 计量

每个值保留unit、precision、completeness、source、scope与时间。数值0只有在源明确报告时显示0；null是缺失，不当0。分母0与分母未知分别说明，不显示0%命中。费用估算不冒充实际扣款；Credits不与Token任意换算。

前端读取源端统一后的增量贡献/修订结果，不自行将cumulative相加。先估算后实报应替代；重试、fork/replay、父子汇总、重复上传、轮转读回和多技能标签不重复计费。重新归属保持总量与源事件。

输入缓存占比 = 同口径缓存读输入之和 / 同口径完整输入之和。请求命中率 = 可判断请求中缓存读>0的数量 / 可判断请求数量。显示可判断子集与分母，缓存写入不算读命中，不平均会话百分比。

演示数值：项目输入58+24+16+2=100K；输出16+8+4+0.4=28.4K；总128.4K。WORK-LAB详情58+16=74K。缓存完整口径输入50K、缓存读30K，60%；4/10可判断请求命中，40%。它们都是示例，不是用户账单、性能或接入事实。

## 能力、规则与命令

源能力身份包含来源/版本/类型，不能同名合并。发现、安装、加载、激活、关联动作、技术结果和用户判断分别保存。许可、依赖、权限与可迁移性决定方案范围；验证绑定源/目标/适配器版本与实际输入。

规则意图→投影生成→写入→原生加载→行为样例验证分别显示。前态/发布态/原生现态三方比较，用户现态变化即冲突，不静默覆盖。恢复仅触及本次发布内容；并发编辑无法安全恢复时保留冲突。

命令资格由服务端返回：观察/建议/受管执行角色、真实授权主体、限定对象、范围、版本/摘要、前态、幂等和到期。摘要只能证明关联，不能证明授权。按钮隐藏、loopback或MCP连接不代替后端校验。已授权正向操作也要实际成功。

## 协作

分别保留出域授权、发送、接收、知识治理、教学工件/专业接受、同版本技术校验、真人学习评价、反馈处理和效果测量。对端身份来自真实对端；本地demo编号不证明接入。

WORK-LAB提供技术候选与检查，AAOS组织知识和学习，DESIGN-LAB拥有作品和专业判断。反馈绑定知识/教学/技术版本；旧版不能覆盖新版。人的完整回答留AAOS，本方仅获技术责任所需摘要。对端不可用时协作局部降级，核心观察可继续。

## 隐私与可靠性

默认字段白名单不含私人提示词、回复正文、工具参数、学习者完整回答；目录和元数据也要审查。按需诊断明确project/problem/time/retention与授权。Hook快速返回、有界缓冲、不唤醒模型、不改变批准、不等待远端阻塞原生流程。

单适配器故障不清空其他数据；缓存上次可见结果需标时间。补齐依赖源支持历史读回，不由UI猜补。暂停滚动和停止采集分别表示；资源、增长、积压和延迟需实际测量，不沿用示例图数字。
