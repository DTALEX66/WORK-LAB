# UI验收与交付

本轮设计包的验证与实际产品验收分开。当前仅做母版视觉检查、素材解码/尺寸/索引/来源/身份/数值守恒/脚本语法等静态检查。没有浏览器交互端到端、Windows、真实客户端、生产接口、真人学习或发布验收。参考原型无需浏览器安装即可由用户打开；本轮自动浏览器依赖未取得，未将其写成测试通过。

下表是执行Agent需与既有必要测试合并的场景，不是本次全部已通过。

| 编号 | 场景 | 通过条件 |
|---|---|---|
| A01 | 新会话冷启动 | 默认入口准确回答项目级监控、外部软件执行、能力迁移、三方职责与未来范围 |
| A02 | 主要入口 | 用户目标可达，避免重复首页，不把“五个”冻结为永恒断言 |
| A03 | 多软件同项目 | 参与集合、运行/等待/受阻并存；不取单个最近软件覆盖其他 |
| A04 | 三轴状态 | 工作、健康、观测独立；断连不等于软件停止 |
| A05 | 多目录与同名身份 | 非Git、worktree、同名项目正确归属，不按名字合并 |
| A06 | 未归属计量 | 未知身份保留未归属；纠正归属保持总量 |
| A07 | 时间与新鲜度 | 源时间/接收/显示分开；last-good明确；事后导出不称实时 |
| A08 | 零与未知 | 实报0、缺失、隐藏、分母0和不可计算分别解释 |
| A09 | 用量单位 | Token、Credits、订阅额度、费用与机器资源分开 |
| A10 | 精度/完整性 | 混合精度不提为全部精确；已知精确子集不丢 |
| A11 | 累计与修订 | cumulative不重复相加，估算→实报替代而非追加 |
| A12 | 去重反例 | 重试/父子/fork/replay/多技能/轮转/重复上传总量守恒 |
| A13 | 缓存占比 | 同口径完整输入之和作为分母，不平均会话百分比 |
| A14 | 请求命中率 | 可判断请求分母，缓存写入不计读命中 |
| A15 | 覆盖范围 | 无全局请求基准不显示虚构98%等覆盖率 |
| A16 | 软件资格 | 绑定版本/形态/鉴权/适配器/字段；更新后待复验 |
| A17 | 有限支持 | CLI/IDE/网页单独核对，MCP不等于全量活动可见 |
| A18 | 能力来源 | 同名不同来源/修订不合并；安装、加载与有效使用分开 |
| A19 | 源评价 | 有真实适用场景、反例与局限，调用量不代替评价 |
| A20 | 目标迁移 | 用户选目标，许可/依赖/权限与能力损失可看 |
| A21 | 目标验证 | 至少一条实际目标输入输出/读回；源验证不替代目标验证 |
| A22 | 配置分阶段 | 投影、写入、加载、行为验证各有真实状态 |
| A23 | 编辑冲突 | 三方比较保护用户改动，不能静默覆盖 |
| A24 | 恢复 | 仅恢复本次触及内容，并发变化时保留冲突 |
| A25 | Observer | 搜索/筛选/复制/展开可用；无业务状态写权限 |
| A26 | 受管命令 | 后端检查授权/目标/范围/版本/前态/幂等；无自授权 |
| A27 | 正向路径 | 已授权、源支持、正常条件下真实接入/配置/读回成功 |
| A28 | 旧深链 | 原task/execution/evidence身份和命名空间正确，不跳错对象 |
| A29 | 兼容错误 | 缺失/权限/历史/不支持分别说明，保持原ID |
| A30 | 采集默认 | 后台字段白名单收敛；不只隐藏UI，不采默认私人正文 |
| A31 | 限定诊断 | 指定project/problem/time/retention与授权，无全量任务监控 |
| A32 | 局部降级 | 单适配器失败不清其他来源，last-good有时间 |
| A33 | 生命周期 | 暂停滚动/停止采集/关窗口/停外部软件分开 |
| A34 | 新事件焦点 | 不抢输入/选中项/阅读位置；通知归并 |
| A35 | 键盘与中文 | Tab/Ctrl K/Esc及焦点回退；IME组合不误触 |
| A36 | 字体/尺寸 | Windows2560×1440，100/125/150/200%DPI，长路径与字号缩放不截断 |
| A37 | 浅深与减动 | 状态不用颜色单独编码，文字对比和减动实测 |
| A38 | 生成链 | 改源再生；二次运行无未解释漂移，时间戳不代替验收 |
| A39 | 权威与归档 | 现行入口一致，旧指令不回流，原失败/哈希/缺陷仍可追溯 |
| A40 | 协作未接入 | AAOS不可用不阻塞核心监控，不伪造接收或教学引用 |
| A41 | 接收与版本 | 真实回执绑定候选/摘要/接收方/修订；重试不重复，不同内容冲突 |
| A42 | 教学与学习 | 实际教学工件、专业接受、同版本技术检查、真人学习分别证明 |
| A43 | 反馈责任 | 旧版不覆盖新版；知识/设计/技术/学习分别返回，未测效果保留未测 |
| A44 | 生产数据隔离 | 演示fixture不进入生产默认读模型或状态种子 |

UI5协作案例按真实合同另验收，不把A41–A43全部作为独立监控发布前提。源验收完整记录保留在inputs，本文不取消原有效安全和行为保护。

每条产品验收记录源码/构建、设备、客户端/适配器版本、输入身份、实际操作、读回断言、证据、范围与限制。截图好看不证明接口可用；退出0、文件存在、测试通过、真人/专业接受和发布分开。

结束报告包含实际变更和截图、23路由迁移账、合同/最小采集、命令权限边界、源再生与冷启动、必要CI、Windows与故障恢复、未执行/未接入/未发布、恢复点。按实际范围报告，不用提交数/页数/门禁数计算完成率。
