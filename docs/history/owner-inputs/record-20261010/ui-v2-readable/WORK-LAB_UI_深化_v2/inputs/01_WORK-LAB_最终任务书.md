## 1. 目标与完成含义

将 WORK-LAB 收敛为软件中立、本地优先的 AI 工作观测与配置治理工作台：用户继续在外部 AI 软件中执行项目，WORK-LAB 以项目为默认主体，观察活动、参与软件、主要阻碍和资源消耗；评价好用能力并将其适配到用户选定软件；管理自己获准维护的规则、配置与能力版本。

同时全面对账产品定义、当前范围、接口职责、前端、默认采集、Agent 指令、生成源、索引、测试、历史与分发副本，避免后续执行器从旧材料恢复错误范围。

全面检查、定向修订、可恢复归档。保留有效实现和历史事实，保留未实现的长期目标；延后或被替代不能记为实现完成。只更新文档不能证明产品可用；退出码为 0、文件存在也不能证明业务完成。

本包包括三套先前原始资料及其完整展开副本、最终决定、任务与验收映射、复跑脚本和证据。覆盖可见对话与已取得的三个资料包；早期逐字聊天全文未能检索，不宣称包含不可见原文。早期报告中的内容完整保留，并按本任务书说明其现行适用性。

## 5. 当前产品行为合同

### 5.1 项目监控与身份

项目默认展示参与软件、活动/等待/阻碍、资源摘要、来源和新鲜度。同项目可同时有运行和受阻会话，不只选择一个 agentPlatform。软件视角可反查参与项目。

支持非 Git 项目、多目录、worktree、同名不同项目；项目身份不能只凭名字或远端 URL。运行、访问目录、计费归属分别记录。跨项目关联不能重复计费；未知放未归属，纠正归属保持总量守恒与原事件。

设备/软件安装/运行实例/会话等身份按来源命名空间隔离，避免 PID 复用和跨客户端会话 ID 混淆。更细事件只保留归属、计量、去重所需字段；不为画全链路默认保存私人正文。

工作、健康、观测三轴分开：工作可运行/等待/本轮结束等；健康可重试/疑似停滞；观测可延迟/断连/有限/不支持。Stop 或 turn_end 不代表项目完成，观测断连不代表软件停止，无日志不能自动判失败。

事件发生、源发出、接收、显示时间分别看待；优先源序列和因果身份，说明时钟与无序列限制。仅结束后导出的源标为事后可见，增加 UI 刷新不能伪造实时。

### 5.2 客户端接入与运行结构

优先盘点 Hermes、Codex、Qoder、DSH，按实际安装版本、形态和可用样本选择两个做首个真实切片；其他客户端保留明确的有限支持，不以固定名称列表锁死未来。

原研究还包含 Claude Code、Cursor、VS Code Copilot、OpenCode、Gemini CLI、纯网页软件，以及 OTel/ACP/MCP/Agent Skills、ccusage/Langfuse/Ruler/Grafana 等参照。完整矩阵和35项历史来源在 `source_packets/research/`。这些是当时官方资料调查，执行时需要对当前版本核验；不是本机已经接入的证明，也不要求重新部署所有参照项目。

资格绑定 software/version/surface/auth_mode/adapter_revision/enabled_fields。CLI、IDE、桌面、云端和网页分别验收。网页只用受支持官方出口，不探读私人浏览器会话；MCP 接通不等于旁观全部活动。OTel 是信号基础、ACP 是交互、MCP 是工具上下文、Skills 是能力格式，不能当万能互换协议。

保留 React/TypeScript/Vite、Tauri/Rust、Python 现有分工。原生事件经字段白名单、有界缓冲、快速返回进入既有核心，再供同一桌面/浏览器前端查询；不另造 UI 和费用真源，不强制大型消息队列、分析库、向量库。

窗口和采集解耦；明确退出采集后外部软件继续工作。仅源支持缓冲/历史读回时补齐，否则显示缺口。常态观测不调用 LLM；真实测 CPU、内存、增长、积压/丢弃和查询时延，不能承诺未测的资源占用。

### 5.3 用量与缓存

Token、Credits、订阅额度、费用和机器资源分单位、来源与作用域；估算费用不冒充扣款。原生请求/尝试身份、delta/cumulative、模型、普通/总输入、缓存读写、输出/reasoning 子集、精度/完整性和归属在源端适配，前端不自行重解释。

真实 0、缺失、分母为 0 分别显示；先估算后实报是替代/修订，不计两次。父汇总和子请求、fork/replay 历史、重复上传、轮转重读、主链与辅助链都需去重守恒。多个技能关联同请求不使总费用倍增。

缓存输入占比=同口径缓存读取输入总和÷完整总输入总和；请求命中率=可判断请求中读缓存大于0的数量÷可判断数量。不可平均会话百分比、不可把缓存写入当命中。提供方字段按 API/版本映射；原研究 OpenAI 与 Anthropic 口径仅作历史夹具依据，当前映射需核验。

质量采用字段级精度与完整性，项目和总体共享规则；混合精确、估算、未知不能提升为全部精确，也不应抹掉已知子集。覆盖率要有可定义分母，没有全部请求基准不声称全局采集98%。

### 5.4 能力资产与软件自身进化

区分插件包、Skill、MCP 服务、Tool、Hook、规则包、适配器及依赖关系；同名不同源/版本不合并。发现/安装/加载/激活/关联动作/结果分别记录，不能凭读过或提到就宣称有效使用；身份被隐私隐藏时明示，不能靠偷读会话补齐。

主流程：源软件实际评价与用户判断→可迁移性/权限/许可/依赖检查→最小中立化→用户选目标→预览差异与能力损失→隔离试用→目标验证→获准部署与版本维护。保留源版本、目标版本、适配器版本、测试和恢复点。失败可回退，不默默覆盖原件。

可吸收客户端自进化形成的能力成果，但不宣称复制其全部进化机制。新增内容分流：运行脚本/配置走资产变更，长期事实/经验走 AAOS 候选，临时会话状态有界保留；原生追加文本不自动升级全局权威。混合知识与执行技能包用清单/引用保持相对路径与运行依赖，不为分工拆坏包。

### 5.5 规则、配置与权限

规则意图→原生投影→写入→实际加载→行为样例验证，状态分开。Prompt guidance 不是不可绕过权限；硬边界依靠原生权限和可验证守卫。

复用 config-ownership 的前态、本方发布态、原生现态比较，保留用户编辑；变化预览、限定目标、版本绑定、最小写入、实际回读和恢复。只恢复本次发布触及的内容，并发编辑不能安全恢复时保留明确冲突。

观察、建议、受管执行分开。Observer 只读业务；获准配置/资产操作用独立命令入口，服务端校验来源、授权、范围、前态和幂等身份。loopback 或隐藏按钮不是授权证明。原生取消/重启/换模型属单独未来资格化能力。

开发 WORK-LAB 的 TaskLedger、单写者、审查和必要 CI 可以严格；这些规则不自动变成所有外部项目的产品使用要求。

### 5.6 隐私、可靠性与正向路径

默认最小字段，不落盘/上传私人提示词、返回正文、参数和学习者完整回答。元数据也须审查；按项目/问题/时间限定诊断和保留。canary 用合成秘密，不用真实凭证。

Hook 不注入后续上下文、不额外唤醒模型、不改变批准、不等待远端服务阻塞原生流程；按实际异步语义验证。采集器有界队列、恢复游标、重启/轮转去重和自身健康。单适配器故障局部降级，last-good 有时间，其他软件和历史仍可读。

不仅测拒绝：已获准、源支持、正常条件下的接入、计量、配置变更和回读必须真实成功。

这是六项语义，不是六套服务或已部署 API。对端地址、端点、传输方式需真实双方合同确认。历史候选表示映射到一个公共版本，不复制另一套机制。相同身份+修订+内容重试不重复；相同身份+修订但不同内容返回冲突。摘要只证明字节关联，不能证明授权、可信或真人接受。

版本关联：源提交/技术依据→候选修订→AAOS 知识与学习目标版本→DESIGN-LAB 教学版本→技术校验→AAOS 学习反馈→责任方修订/复验。保留各方状态，不合成总成功。

联合案例：为什么显示 SUCCESS、exit0、文件存在仍不能证明完成？真实源码依据是回执序列化失败；S1空文件、S2合法JSON却2+3=6、S3正确2+3=5为新建合成教学输入，执行是真实本地子进程。S1/S2技术失败；S3技术通过，真人接受未执行。不冒充历史生产事故。

最小路径：WORK-LAB 技术包→AAOS 接收并确认知识/学习目标→DESIGN-LAB 可编辑视觉讲解与先判断后看结果的练习→WORK-LAB 绑定实际教学版本的技术校验→真人在 AAOS 判断、说明理由、完成不同迁移题→按责任反馈和工作复验。机器可判题，不能代答或凭点击宣布长期掌握。没有缺陷可记录真实无缺陷反馈，不伪造改善。

知识依据/条件问题归 AAOS；图示交互表达归 DESIGN-LAB；示例代码/工具复现归 WORK-LAB；学习目标/组织/评价归 AAOS 人类学习侧；不明归属共同分诊。

联合通过须有真实接收回执、实际教学工件与专业验收、同教学版本技术结果、真人学习与评价、反馈读回和适用范围工作记录；改善没测仍未测。负向覆盖未授权附件、摘要不匹配、身份内容冲突、旧反馈不覆盖新版本、AAOS 不可用不阻塞监控。
