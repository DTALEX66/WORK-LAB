# 操作状态、错误与恢复

以下是前端显示要求，不新增一套后端业务状态。执行Agent映射当前合同；若原状态不同，保留原值与来源，转换仅在显示层发生。

| 流程/触发 | 当前显示 | 下一步 | 不可推断 |
|---|---|---|---|
| 导入选择来源 | 待预览，现有对象未改 | 格式检查、许可与依赖、内容差异 | 文件名正确不等于包有效 |
| 导入同身份同摘要 | 已存在 | 打开原版本 | 不创建重复资产 |
| 导入同名不同身份 | 名称冲突提示 | 展示来源/版本后人工选 | 名称不等于对象身份 |
| 来源评价未取得/尚不能判断 | 待评价 | 样例任务与证据、用户判断 | 安装/调用成功不等于有效 |
| 目标未选择 | 尚不可迁移 | 选择具体安装与范围 | 不默认选择某软件 |
| 目标更新待复验 | 资格待复验 | 现场资格校验 | 旧版本资格不继承 |
| 目标/源/范围/方案变更 | 旧证据失效 | 重算差异，重试与重验 | 旧结果不能解锁新方案 |
| 试用提交/排队/运行 | 当前阶段 + 最后可信进度 | 查询同一操作、取消 | spinner不等于正在原生执行 |
| 试用依赖失败 | 失败原因 + 已触及范围 | 依赖修复后新试用 | 失败不代表项目失败 |
| 试用取消后晚到结果 | 已取消，忽略过期结果 | 重开新操作 | 晚到通过不能复活旧方案 |
| 查询超时/观测断连 | 状态未确认 + 上次可信状态 | 按操作ID重查 | 不伪造终态或自动重复写入 |
| 目标验证未实际加载 | 验证未通过 | 查看加载/路径/适配器，复验 | 源端评价不代替目标验证 |
| 命令资格不足 | 操作不可用 + 服务端原因 | 阅读、资格复验/取得管理权限 | 前端勾选不授予真实权限 |
| 发布已提交但回执未知 | 发布结果未确认 | 查询同一幂等操作 | 不生成新键重复提交 |
| 写入成功 | 已写入，加载待查 | 读回原生目标 | 不自动显示“部署成功” |
| 读回不一致 | 加载未确认/失败，版本差异 | 原生读回修复、限定恢复 | 写入成功不等于加载 |
| 加载成功但行为失败 | 行为未通过，加载事实保留 | 修复复验或限定恢复 | 不覆盖加载事实或技术证据 |
| 限定恢复条件齐备 | 可预览恢复 | 复核范围与现态后恢复 | 不清空整个客户端配置 |
| 恢复遇用户编辑 | 恢复冲突，保留现态 | 重读并限定合并 | 不使用旧摘要覆盖新现态 |
| 恢复写入完成 | 本次范围已恢复，待复验 | 读回加载与行为 | 不标工作效果正常 |
| 首次接入写入完成无活动 | 等待最小字段样例 | 指引实际样例活动 | 无日志不等于失败 |
| 首次接入字段不支持 | 不支持 + 原因 | 选支持字段或换出口 | 不显示0替代未支持 |
| 规则三方字段冲突 | 前态/发布态/用户现态 | 用户选择保留/限定采用 | 不默认覆盖用户值 |
| 规则预览后现态变更 | 合并预览过期 | 重读现态和重新预览 | 旧预览不得提交 |
| 协作无真实回执 | 未取得/未发送 | 留本地技术候选 | 不推断对端接受或学习效果 |

失败文案应包含“哪里失败”“当前已发生什么”“可以做什么”。避免仅写未知错误。具体实现以现有错误码和证据字段映射，不凭设计枚举新的HTTP状态码。

## 原型演示路线

- 主路径：能力资产→评价→选择目标Hermes→审查许可/损失→启动试用→目标验证通过→开启演示管理资格→限定发布→读回一致→行为通过。
- 失败路径：试用结果选择依赖失败→启动→失败说明→修复后重试。试用运行期间可取消，晚到结果不会更新。
- 恢复路径：发布→读回失败→恢复本次范围，结果保持待复验。
- 并发路径：发布后模拟原生侧编辑→恢复→冲突保留现态。发布前编辑→发布门禁关闭→重新读取前态→重新试用和验证。
- 接入：软件→接入向导→选择Codex→改选字段→确认差异与演示授权→写入→模拟读回→模拟活动。选Qoder/DSH会提示资格不足。
- 合并：规则→选保留/采用→预览→开启演示管理权限→提交；预览后模拟继续编辑→提交返回冲突。
- 资产：导入来源元数据→点击该行详情→来源评价；原型尚不解析真实文件。

目标选择、评价与恢复始终绑定当前演示对象。演示中的单活动发布终态请重置后重开；生产必须保留多版本与历史操作。本原型不会模拟后台队列与真正的跨进程取消。
