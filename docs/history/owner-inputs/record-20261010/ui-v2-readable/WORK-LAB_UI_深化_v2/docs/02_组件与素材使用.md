# 组件、画面与素材落地

## 页面拆分

| 组件 | 输入和行为 | 日常呈现 |
|---|---|---|
| AppShell / NavigationDrawer | 路由、身份、主题、主内容焦点 | 不作固定大画布缩放 |
| ProjectSummary / ParticipantTable | 真实项目和参与者、三轴状态、来源时间 | 事实优先，身份可复制 |
| ObservedMetric | 值/单位/精度/完整性/范围/来源 | 0、未知、不支持和不可计算分别显示 |
| SourceImportPreview | 解析、身份/摘要比较、许可/依赖/权限 | 明确导入范围，重复与冲突单独处理 |
| SourceEvaluationForm | 样例/证据、用户判断/适用条件、版本 | 技术事实与用户评价分别保存 |
| QualifiedTargetPicker | 安装/形态/软件版本/适配器/资格/字段 | 用户选目标；禁用项展示原因 |
| MigrationPlan / NativeDiff | 原/目标/范围/损失/版本/前态 | 先差异后试用，详情可折叠 |
| OperationProgress / EvidenceLog | 操作ID、阶段、最后可信进度、证据 | 未确认回执不显示成功；日志按需展开 |
| CommandGate | 后端可用性、原因、权限/范围/前态 | 与对象操作一起呈现，前端不授予权限 |
| DeploymentReadback / ScopedRecovery | 写入、加载、行为、恢复点和并发比较 | 每阶段显示真实结果和下一步 |
| OnboardingWizard | 可选安装、支持字段、差异、读回与活动 | 不预选未确认的软件，不默认全字段 |
| ThreeWayRuleDiff / ScopedMerge | 前态/发布态/现态及冲突解决方案 | 用户编辑保留，过期预览停止提交 |
| InlineHelp / ErrorPanel | 来源/权限/缺口/具体修复办法 | 不用永久大段教程压住当前状态 |

## 图像用途

桌面母版1600×900绘制并输出3840×2160。窄屏390×1120绘制并输出1560×4480，是4倍宽度渲染，不能称为3840×2160的4K桌面图。所有图均为同源场景排版，未由浏览器抓取。

`design/svg/`文字转曲，可无损放大。`design/scenes/`的text操作保留原文字与坐标，可编辑后用脚本重绘。`assets/slices/`是显式区域切片，精确坐标见manifest；截图和包含动态文字的切片只作设计参照，不作生产文字图。静态线性图标可直接作为组件资产，颜色用currentColor。

实现优先复用仓库既有组件和已确认品牌。此次未声明换正式LOGO；WORK-LAB文字标识是设计占位。不要重新加入旧的EXECUTION CONTROL PLANE定位副标题。

## Agent切片、放大与生成资产

- 找到page_manifest中的场景ID和逻辑尺寸，再从slice_manifest读取区域与render_scale；优先使用已交付切片。
- 图片裁切使用pixel_rect，矢量区域导入时使用logical_rect；不要混用坐标或把2.4倍/4倍再次乘入。
- 如需大幅输出，优先直接使用转曲SVG。修改文案/间距应修改scene生成源或真实组件，不能扩图“猜”文字。
- 生产图标维持24×24、1.6描边、圆端点，复用既有图标系统。表单控件、图表、文字与状态徽标应代码实现，不生成照片素材。
- 若未来确需装饰插画，再按已确认VI生成无文字独立透明资产，并交付尺寸、用途与许可证来源；当前操作工作台无需装饰图。不要为背景增加空间、霓虹或不相关品牌风格。

示例资产说明：能力导入空态可采用现有assets线性图标+文字+真实按钮，不需要一张无法编辑的合成UI图片。

## 复现

Python依赖：Pillow、fontTools、PyMuPDF。Node用于语法与模型测试。执行：

```bash
python3 tools/build_refinement.py
node tools/test_model.cjs
python3 tools/validate_refinement.py
```

build_refinement调用render_base的绘图/转曲工具；render_base中的旧页面工厂仅作为历史绘图实现保留，**不要运行render_base.main生成旧原型**。统一当前入口为build_refinement.py。生成时临时提取可用CJK字体作渲染，不把该字体文件再分发。交付DejaVu字体附原许可证，用于参考重绘，不要求生产使用。
