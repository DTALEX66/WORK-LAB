## 仍需重点处理的实现风险

1. 后端是否有现成的资格、原生差异、隔离试用、加载读回与限定恢复合同必须先核对；UI不能通过本地状态自行补齐。
2. 原生格式可能不是单字段JSON。必须按当前适配器实际结构处理三方合并、范围与摘要，保留手动编辑。
3. 实机软件的官方可观测出口、支持字段、版本变化和资源开销仍需验证。页面不能宣称接通就取得全部活动。
4. 大量数据时不要每个刷新重绘整页。生产组件使用既有订阅、分页/虚拟化、焦点/草稿保留；本地演示的innerHTML更新不适合作为实现模式。
5. 原型包含基础原生dialog焦点行为和composition保护；移动抽屉焦点约束、屏幕阅读器与Windows真实IME/DPI还需验收。布局规则写入不等同浏览器已验证。
6. 演示来源导入只是元数据；真实包解析、许可核验、证据及持久化不能省略。图示与原型的这一区别已标明。

可以开始开发；目前不能宣布“成熟可直接部署”。生产发布前，接口矩阵每项需要真实位置/证据或有依据的“不适用”，验收清单阻断项需要真实通过记录。对端长期学习与教学不作为本次独立项目监控的发布前提。
