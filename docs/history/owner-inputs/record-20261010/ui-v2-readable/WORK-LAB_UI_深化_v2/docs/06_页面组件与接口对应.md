所有页面路由名只表示功能，不创建新路由权威；对照当前仓库决定沿用、兼容或补充。

| 01_projects | ProjectSummary、ParticipantTable、SourceFreshness、ObservedMetric | B01–B08 | 项目身份独立；三轴与三种时间；未知归属与计量守恒 |

## 绑定矩阵填写示例（不含虚构API）

B03 的 `current_contract` 填实际仓库中已存在的合同名；`actual_field_paths` 填真实work/health/observation来源字段；`source_file_or_symbol` 填读取器/适配器/组件位置；`error_mapping` 填来源未知或过期时实际返回值的UI含义；`evidence` 填测试或截图路径；核对后将 `binding_status` 改为“已绑定”。无对应合同写“缺失，需仓库补齐”及阻断影响，不能写想象中的URL。

已绑定还要测试：权限边界、版本一致性、source/null/unsupported状态和现场结果。通过的接口不是其他字段/其他形态的通用资格。
