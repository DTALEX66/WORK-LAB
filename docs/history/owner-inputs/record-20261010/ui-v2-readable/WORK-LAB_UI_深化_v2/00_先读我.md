# WORK-LAB UI 深化 v2 · 增量任务包

承接 2026-10-09 UI 包和本轮成熟度评审，保留原导航、产品边界与主题，补齐操作、状态、自适应布局及接口绑定工作。本包是实施输入与可操作演示，不是现有仓库已经完成这些修改的证明。

1. 执行 Agent 先读 `01_深化实施任务书.md`、`02_AGENT执行提示词.md`。
2. 双击 `prototype/index.html`，体验真实 HTML 表单、流程切换和页面内模拟状态。无安装、无网络、无原生写入。
3. 看 `design/00_深化界面总览.jpg`；`design/png/` 有 8 个桌面场景×2主题和2个窄屏场景×2主题，共20张图。桌面3840×2160；窄屏1560×4480，逻辑宽390。
4. `design/svg/` 为文字转曲矢量图；`design/scenes/` 保留可编辑文字、坐标和颜色。`assets/slices/` 及 `contracts/slice_manifest.json` 提供精确区域裁切信息。
5. 在当前仓库执行 `docs/03_接口绑定矩阵.csv`，填写真实合同与源码位置，然后执行 `docs/05_验收清单.csv`。未绑定项不允许以演示值填补。

## 交付物怎样使用

| 内容 | 已提供 | 生产实施还需要 |
|---|---|---|
| 项目首页与详情 | 过滤、搜索、三轴状态、独立项目身份 | 接入现有项目读模型；真实源时间与缺口 |
| 能力导入与评价 | 元数据录入、重复提示、评价表单 | 现有能力包解析、来源验证、真实证据与评价存储 |
| 目标选择与迁移 | 手动选择、条件门禁、可失败的试用与目标验证 | 真实目标资格、隔离试用服务、版本绑定 |
| 发布与恢复 | 写入/读回/行为分开；并发编辑及限定恢复模拟 | 后端鉴权、幂等与摘要比较、原生写入与恢复 |
| 首次接入 | 可改的软件、字段、差异确认、读回/活动状态 | 真实发现与资格、现有配置预览、版本升级复验 |
| 规则合并 | 三方字段比较、用户选择、过期预览冲突 | 现有规则发布、后端并发保护、限定恢复 |
| 自适应布局 | HTML/CSS重排；语义表格、44px操作区 | 浏览器视觉验收、Tauri/Windows DPI与中文输入 |

效果图是依据设计场景生成的排版参考，**不是浏览器截图**。导入图展示的包解析预览为生产设计要求；原型只录入来源元数据。带动态文字的切片用于对照，实际界面用组件和实时文字，不作为整页背景。图标可按既有组件方式复用。

本轮20张图是10个场景的双主题版本，不是20个不同业务页面。其余业务页沿用 UI v1。本包带原最终任务书、UI v1任务书和说明的只读快照，未将它们升级为新的仓库权威。

## 状态与权限

所有 `demo:`、`fixture-` 状态均为合成数据；“演示管理权限”开关只是探索禁用条件。生产权限必须由后端根据真实身份、对象和范围返回。不要迁移演示开关、演示默认数据或本地 reducer 为生产授权实现。

当前参考原型在内存中保存状态，刷新即重置，不解析真实能力文件、不调用真实软件，不产生学习或协作回执。一个能力对象只演示一个活动发布过程；终态之后用“重置演示”重开流程。真实产品应保留每个版本与操作历史。

已验证与未验证项目见 `verification/validation.json`。本轮验证不包含浏览器E2E、实机接入、Windows安装或生产部署。
