# WORK-LAB 项目定位（2026-10-09）

WORK-LAB是软件中立、本地优先的AI工作观测与配置治理工作台。外部AI软件执行业务，默认按项目观察参与软件、活动、主要阻碍与资源。
能力资产围绕源评价、可迁移性、用户选目标、最小中立适配、损失解释、目标验证、获准部署读回恢复与版本维护。
规则意图适配原生能力，声明字段外的provider/model/auth与用户编辑保留。不是强制通用派工器，不建新运行时/账本/知识主库。
AAOS负责完整知识/人的研究学习/AI学习资产/人机双向学习与长期项目记忆；DESIGN-LAB负责专业设计/原生作品/设计内核/专业接受。
三方各自独立，协作按需；Open Design客户端与DESIGN-LAB项目是不同身份。
Observer和sidecar只读业务，允许搜索筛选复制展开。获准写复用独立Control边界，服务端实际校验授权并读回。
当前UI优先，仅桌面main与既有HUD；手机端不做，不建延后/冻结任务。五目的地是建议，旧深链保留对象身份和明确错误。
默认最小采集，详细诊断限定项目/问题/时间/保留。单位、精度、完整性、新鲜度独立，未知不填0，断连不判停止。
架构保留React/TS/Vite、Tauri/Rust、Python、JSON Schema；模块与配置权威仍分别由既有module-ownership/config-ownership定义。
旧主线未完成项已合并或冻结，历史实现和保护性测试保留；新计划不证明实现，CI/桌面/接受/发布分别核实。
顶层依据：WORK-LAB-AUTHORITY.md与.project/governance/project-authority-index.json；唯一CURRENT见taskpack-authority-index.json。
