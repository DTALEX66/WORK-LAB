## 4. 包内自相矛盾（不替它选一个，报出来）

1. 侧栏宽度：`design_tokens.json:44` 说 **222**，任务书 `:29` 说 **216**，`:30` 说 768–1199 带 **184**——同一包三个值，且 768 带本身属被删的手机范围。
   仓现行是流体 `clamp(210px,17vw,280px)`（`src/skins/l10b-shell.css:493`），实测 2560 宽 **280**、1280 宽 **217.6**
   （`.project-local/artifacts/wui-20261009/display-scaling.json`）。222 这个固定值在当前布局下任何宽度都不会产出。
2. 字号：任务书 `:33` 要「正文14px」，同一包 `:10` 又要求「字体不整体缩小」。当前 `body` 无 font-size 声明（默认 16px），
   `apps/observer/frontend/DESIGN.md` 的 `body-md` 亦为 16px/1.5 —— 14px 是把正文缩 12.5%，与包自己的禁止缩小条款冲突，也与本仓以 16px 为基线
   测过的全部对比度/几何数字冲突。
3. 顶栏：`design_tokens.json:45` 说 topbar **63**，而仓内几何门上限 140、实测 78（宽视口）与 129（1280×720）。
   63 低于当前实现的最小值，按 63 验收会把已 PASS 的布局判成缺陷。
