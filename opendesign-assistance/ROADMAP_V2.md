# Roadmap V2

## P0 — trustworthy substrate

- Apply the global source registry, licensing gate and capability evidence levels.
- Upgrade all existing plugin manifests to current Open Design fields without deleting v1 behavior.
- Verify daemon loading and one real task for every promoted plugin.
- Add source/skill security scans and CI.

## P1 — first complete commercial loop

- Run `brand-campaign-360` on three real briefs.
- Emit DESIGN.md + DTCG tokens + key visual + three applications + critique + preflight + handoff.
- Compare each run against no-skill/current-v1 baseline.

## P2 — domain pipelines

- Graphic campaign, UI product, spatial exhibition, packaging, editorial, motion and 3D.
- Each domain receives its own schema extensions, rubric, preflight profile and five benchmark cases.

## P3 — tool adapters

- DTCG/DESIGN.md transform, WCAG JSON, Playwright/axe, SVG/PDF raster preflight, editable PPTX, Lottie, glTF/OpenPBR and provenance/BOM.
- External GPL/AGPL or heavyweight tools remain process-isolated.

## P4 — commercial proof

- Five accepted projects per priority domain.
- Human reviewer agreement and client/production approval records.
- Marketplace-ready packages only after evidence level 4; “commercially proven” only at level 5.
