# Visual Taste Jury

Use five roles: creative direction, typography/composition, image/material, production, culture/originality. Score independently, then compare variants pairwise. Record disagreements and confidence. Require human calibration when the panel is split or the decision is culturally sensitive.

## Output

Write a structured artifact using the closest schema under `opendesign-assistance/schemas/visual-quality/`. Include evidence, uncertainty, forbidden-copy notes and the next bounded action.
