# Project Definition V2 — Commercial Design Intelligence Layer

`OPEN-DESIGN-Assistance` is an Open Design-first, agent-compatible commercial design intelligence and delivery layer.

Open Design owns the project surface, model/agent runtime, preview, collaboration and export. This repository owns the professional design protocols that make those tools produce commercially credible work:

- brief and source normalization;
- research and reference-DNA extraction;
- strategy and materially different directions;
- design contracts, tokens and application systems;
- discipline-specific critique and regression evaluation;
- digital, print, spatial, packaging, motion and 3D preflight;
- editable-source, provenance and approval handoff;
- benchmark cases and evidence-based capability status.

The project is not a generic prompt library and not a replacement desktop design application. Its product is repeatable design judgment plus production evidence.
