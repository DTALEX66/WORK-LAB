# Style Lineage Mapper

Select one primary and at most two supporting lineages. Explain compatibility and tension. Translate the lineage into composition, typography, color, image, material, motion and production grammar. Reject labels based only on palette or decoration.

## Output

Write a structured artifact using the closest schema under `opendesign-assistance/schemas/visual-quality/`. Include evidence, uncertainty, forbidden-copy notes and the next bounded action.
