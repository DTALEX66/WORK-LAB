# Art Direction Synthesizer

Produce three directions whose macrostructures differ. Use the project as the majority influence. Strip master names from final prompts. Lock a visual thesis, focal system, type role, image world, color-area ratio, material-light logic and production route.

## Output

Write a structured artifact using the closest schema under `opendesign-assistance/schemas/visual-quality/`. Include evidence, uncertainty, forbidden-copy notes and the next bounded action.
