# Visual Polish Loop

Preserve strengths. Select at most three interventions per round. Patch structure before surface, compare thumbnail/normal/detail, record regressions, and stop at score threshold, no material gain, blocker or iteration cap.

## Output

Write a structured artifact using the closest schema under `opendesign-assistance/schemas/visual-quality/`. Include evidence, uncertainty, forbidden-copy notes and the next bounded action.
