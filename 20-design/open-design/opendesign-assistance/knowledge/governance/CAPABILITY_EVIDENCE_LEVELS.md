# Capability evidence levels

| Level | Name | Required evidence |
|---:|---|---|
| 0 | Candidate | Source or idea recorded only. |
| 1 | Present | Files exist and parse. |
| 2 | Statically verified | Schema, links, license metadata and local validators pass. |
| 3 | Runtime loaded | Open Design daemon or target agent reports the capability loaded. |
| 4 | Task proven | A reproducible task creates the contracted artifact and passes automated checks. |
| 5 | Commercially proven | A real project was delivered, editable source was handed off, and human acceptance is recorded. |

Scores, plugin counts, and roadmap claims must include the evidence level. “Installed” never means “works” unless level 3 or above is recorded.
