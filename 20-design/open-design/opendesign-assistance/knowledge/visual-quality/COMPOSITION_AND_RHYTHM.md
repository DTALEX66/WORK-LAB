# Composition and Rhythm Craft

1. Establish one macrostructure before styling.
2. Define the first three-second focal event.
3. Use scale contrast before adding effects.
4. Let negative space shape grouping and tension.
5. Control edge behavior: crop, bleed, frame or pause deliberately.
6. Build rhythm through interval change, not repeated equal cards.
7. Keep at least three depth planes only when each has a role.
8. Test thumbnail, normal view and close detail.
9. Use optical alignment, not only geometric alignment.
10. Remove one competing focal event per refinement round.
