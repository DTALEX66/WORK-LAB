# Typography Craft

Typography is evaluated as voice, structure and physical texture.

- role system before font selection
- appropriate line length, leading and paragraph spacing
- optical alignment for curves, punctuation and mixed scripts
- deliberate rag shape and line breaks
- CJK punctuation, vertical metrics and Latin/CJK proportion
- actual weight availability and font licensing
- display type customized only when concept earns it
- no fake hierarchy made only from size changes
- no compressed tracking used to force copy into a box
- export and fallback behavior verified

For high-value work, review the design in monochrome and with images hidden; the hierarchy must still work.
