# Design evaluation system

Each important generation is evaluated against:

1. a no-skill or previous-version baseline;
2. a discipline-specific weighted rubric;
3. deterministic preflight checks;
4. an independent visual/semantic critic;
5. human review for final commercial acceptance;
6. cost, runtime and iteration count.

A skill is promoted only when it improves the median result without increasing blocker failures. Popularity, stars and self-authored demos are not sufficient evidence.
