# MINIGAME UI V3 — 全量重构规格

> Surface：**Monitor（主）+ Operate（辅）**。CCTV 画面承担观察与判断，操作台只服务快速处置；不采用营销页、卡片墙或装饰性仪表盘构图。

## 1. 附件资产包结论

`MINIGAME_UI_All_Assets_Pack_v2.zip` 不直接入库。

- 428 个 PNG 中大量是同一 AI 大图的重复切片、残片和近似按钮。
- 按钮与面板普遍带不可读的烘焙伪文字，不能承载真实中文标签。
- 自动抠图存在背景残留、断边、半个相邻组件和完整源图误判为单组件。
- 缺少可验证的 default/hover/pressed/disabled/focus 成套状态。
- 多数组件不是 9-slice，也没有适合 320–430px 屏幕的缩放规则。
- CCTV 与空白金属框材质方向可作氛围参考，但现有项目已有更完整、无文字的 24 状态 CCTV 资源。

因此 V3 使用 **CSS/Canvas 原生矢量控制件 + 已验证无文字 CCTV 状态图**。UI 文案始终由 DOM/Canvas 实时渲染，禁止烘焙进图片。

## 2. 视觉方向

名称：**Night Relay / 夜班继电台**

- 主材质：消光黑钢、压边、细划痕；不使用大面积透明玻璃卡片。
- 主色：煤黑 `#07090a`、钢灰 `#15191b`、骨白 `#e7e2d5`。
- 功能色：信号绿 `#79d6a3`、继电器琥珀 `#e1a84b`、故障红 `#e75c4f`。
- 字体：标题使用 `Bahnschrift Condensed / Arial Narrow`；读数与日志使用 `Cascadia Mono / Consolas`。
- 边角：2–8px，小半径工业面板；删除 20–30px SaaS 胶囊感。
- 阴影：只表达压入/凸起层级，不做霓虹泛光墙。
- 动效：状态变化 120–180ms；扫描线和异常闪烁低频；支持 `prefers-reduced-motion`。

## 3. 桌面构图（≥900px）

三列控制台：

1. 左列 236px：关键状态在上，系统日志在下。
2. 中列 `minmax(0, 1fr)`：CCTV 独占主视觉，面积不低于可玩区域 55%。
3. 右列 252px：三主操作 + 更多操作，按钮纵向大触点。

顶部压缩为 68px：任务名、信号/班次标识和倒计时；禁止超大海报标题抢占 CCTV。

## 4. 竖屏构图（≤700px）

顺序固定：

1. 52–58px 顶栏；
2. CCTV；
3. 四列操作轨（关门 / 上行 / 急停 / 更多）；
4. 两行关键状态；
5. 系统日志；
6. 开始/结算层。

验收：

- 390×844：四个操作按钮完整显示，不得横向裁切。
- 360×640：短屏允许 shell 内滚动，但首屏必须同时看见 CCTV 和完整四按钮操作轨。
- 所有触控目标最小 44×44 CSS px。
- 横向 `scrollWidth <= clientWidth + 1`。
- 常规竖屏开始按钮完整可见；短屏开始层内部滚动，不能把主按钮挤出屏幕。

## 5. 组件规则

### 顶栏

- 标题不超过两行；桌面单行。
- 倒计时为最高优先级读数，但不能成为独立巨型卡片。
- 信号状态使用小型灯与文本，不使用装饰性英文长串。

### CCTV

- 画面占比优先于外框。
- 保留状态图、scanline、噪点、异常实体和多摄像头辅助栏。
- 正常态必须干净；异常层只在状态触发时出现。
- HUD 标签靠边，不能盖住核心观察区。

### 操作

- 主操作始终 3 个；“更多”始终作为第 4 个位置。
- 使用 CSS/Canvas 绘制凸起键帽、状态灯与真实文字，不使用附件包伪文字按钮。
- 推荐操作用琥珀边框与短脉冲，不整块变黄。
- 急停仅用红色状态灯和压入槽表达危险，避免糖果渐变。

### 状态

- 默认只突出楼层、门、方向、乘客、电源、稳定度、异常。
- 广告复活/解码/待解码降级为次要数据；移动端可隐藏其卡片但不得丢失逻辑。
- 电源、稳定度使用线性刻度，不使用十个等权卡片。

### 日志和弹层

- 日志固定显示最近 3–5 条，重要级别通过图标/字重而非大色块区分。
- 开始层是设备接管卡，不是底部横幅；桌面居中、移动端底部抽屉。
- 成功、失败、假结局使用同一面板骨架和不同功能色。

## 6. Canvas 同步

Canvas 运行时使用相同色板、三段层级、四按钮轨、显式 success/failure 结算和 CCTV 状态 treatment。不得把 DOM 版设计仅实现为浏览器 CSS。

## 8. 实施结果与证据

### 资产审计

- 实测 PNG：`428` 个，合计 `59,028,889` bytes。
- Alpha 图片：`209`；其中 `209/209` 的非透明内容触碰裁剪边界，缺少安全留白。
- 无 Alpha 图片：`219`。
- 至少一边小于 44px：`33` 个，不满足独立触控资产要求。
- dHash 近重复对：距离 0 为 `176` 对，距离 ≤4 为 `500` 对；说明“看似很多资产”中存在高比例视觉重复。
- 附件只保留在桌面解压审计目录，未复制进仓库运行时。

### H5 / Android WebView

- 新增 `UI V3 NIGHT RELAY` 最终覆盖层，桌面采用 `236px / 1fr / 252px` 三列驾驶舱。
- 390×844 实测：页面 `scrollWidth=390`、`scrollHeight=844`；开始卡 `x=6, width=378, right=384`。
- 360×640 实测：页面 `scrollWidth=360`、`scrollHeight=640`；四个操作键分别为 `81×56px`，右边界 `348px`，均完整位于视口内。
- 桌面 1365×768 实测：CCTV 面板 `845×676px`，为第一视觉焦点。
- 成功/失败、档案、更多操作、开始接管层统一为小圆角黑钢面板，移除紫色 SaaS 卡片与高亮青色糖果按钮。

### 微信 / 抖音 Canvas

- 新增可测试的 `getCanvasLayout(1334)`。
- CCTV 置顶，设计坐标画面 `722×510`。
- 操作区固定四列、两行，按钮高度 `88` 设计像素；按约 0.5 缩放到 375px 设备后仍为 44 CSS px。
- 绘制和点击命中共享同一布局数据，避免“视觉位置更新但点击热区仍留在旧位置”。
- 移除生产 Canvas 中的“触发异常测试”按钮，仅保留真实操作。
