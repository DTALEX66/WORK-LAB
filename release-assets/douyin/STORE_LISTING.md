# 抖音小游戏上架文案

## 名称

异常电梯控制台

## 一句话介绍

盯住 CCTV，核对画面与三项数据：一致放行，矛盾封锁。

## 详细介绍

你接手的是一部没有出现在完整图纸里的夜班电梯。每班到达时都要核对 CCTV 画面、楼层、人数和门状态：全部一致就放行，发现任意矛盾就封锁。封锁后系统会自动处置，玩家只需专注观察和判断。

- 60 秒一局，随时可重新挑战；
- 前两班在真实画面中教学，第三班开始独立判断；
- 16 类异常事件与动态 CCTV 线索；
- 玩家可操作判断始终只有“放行 / 封锁”；间歇和系统处置期间显示不可点击状态；
- 黑钢 CCTV 工业悬疑视觉；
- 无付费购买，激励广告均为主动选择。

## 建议分类与标签

- 分类：休闲 / 益智 / 观察判断
- 标签：找异常、监控、电梯、悬疑、60秒挑战
