# 数据与 SDK 清单

## 游戏业务代码

| 类别 | 当前状态 | 用途 | 保存位置 |
|---|---|---|---|
| 账号信息 | 不收集 | 无自有账号 | 不保存 |
| 手机号 | 不收集 | 无 | 不保存 |
| 定位/相机/麦克风/相册/通讯录 | 不申请、不收集 | 无 | 不保存 |
| 剪贴板 | 不读取 | 无 | 不保存 |
| 游戏行为 | 不上传 | 单局状态机运行 | 仅运行内存 |
| 音效偏好 | 本地保存布尔值 | 记住静音选择 | `tt.setStorageSync` 本地存储 |

## 平台能力

- 抖音小游戏运行时 `tt`：Canvas、触摸、生命周期、安全区、本地存储。
- 抖音激励视频广告：复活、日志解码、结局真相；完整观看后才发放奖励。
- 抖音侧边栏复访：仅调用官方 `navigateToScene({ scene: 'sidebar' })`，不自建用户画像。

项目不包含自建网络请求、第三方统计 SDK、第三方登录 SDK、支付或外链下载。
