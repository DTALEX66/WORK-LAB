`git add -u taskpacks/` 第三次把并行写者的 `error-ledger.json` 扫进我的提交；清理时我又用

`git fsck --unreachable` 找 dangling commit → `git show <c>:<path>` 与 `.project-local/runs/writer-files-before.txt`
的 sha256 比对 → 命中即写回工作区（本次命中 `2100467f1b`）。四文件 sha256 全 OK。

只能用 `git reset` 撤出索引 + 保留工作区内容。**
