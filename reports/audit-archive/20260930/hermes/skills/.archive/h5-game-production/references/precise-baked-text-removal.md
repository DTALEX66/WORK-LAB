# 精确移除 CCTV 素材中的烘焙文字

## 适用场景

用户明确圈出素材内某一行固定文字（例如 `7F→8F`），但要求保留整张电梯/CCTV 图及其构图、轿厢、门、箭头、扫描线和环境质感。

## 先拆解用户范围

把画面分成四层，禁止混淆：

1. **原始素材层**：电梯主体、透视、箭头、纹理，以及烘焙文字。
2. **运行时状态层**：当前楼层、方向、门、人数。
3. **Renderer 层**：素材绘制、HUD、扫描和异常特效。
4. **数据面板层**：玩家拿来核对的主控读数。

当用户说“去掉红圈里的 `7F→8F`”，默认含义是：**只删除素材层中该字符串**。不要推导成删除整张素材、添加黑条、添加中央黑卡，或增加第二套楼层显示。

## 正确工作流

1. 先查看原图，记录尺寸与目标文字边界框。
2. 同时检查上行、下行和桌面/移动变体；固定路线常分别是 `7F→8F`、`7F→6F`。
3. 仅对文字颜色像素建立紧边界 mask：
   - 限制在文字 bbox 内；
   - 使用颜色差阈值筛出青绿色字形；
   - 轻微膨胀 1 次覆盖抗锯齿边缘；
   - 不把箭头、中央竖线或轿厢边缘纳入 mask。
4. 用 OpenCV `cv2.inpaint(..., radius=3, INPAINT_TELEA)` 修复局部纹理。
5. PNG 使用无损优化重新保存，避免局部修补让包体显著增大。
6. Renderer 恢复为正常绘制完整素材；删除此前用于遮挡的黑条、黑卡和重复楼层 overlay。
7. 重新构建目标平台并同步生成资产。
8. 双重视觉验收：
   - 直接检查处理后的源 PNG；
   - 在官方开发者工具截图中检查运行时。

## 验收清单

- [ ] 电梯轿厢完整保留
- [ ] 门框、箭头、中央竖线完整保留
- [ ] 扫描线、透视地面、环境纹理完整保留
- [ ] 固定路线文字完全消失
- [ ] 没有黑条、黑卡或明显修补痕迹
- [ ] 没有新增重复楼层显示
- [ ] 上行/下行、桌面/移动变体均处理
- [ ] 目标平台构建与完整测试通过

## 回归保护

Renderer 源码测试应禁止重新引入宽黑条，例如断言不存在移动态 `barH` + 全宽 `fillRect` 组合。素材像素级检查优先使用视觉验收；如果项目已有图像测试依赖，可增加固定 bbox 内目标字形色像素数量上限。

## 核心原则

> 用户圈哪里，就只修哪里；保留周围内容，不用大范围遮挡掩盖素材缺陷。
