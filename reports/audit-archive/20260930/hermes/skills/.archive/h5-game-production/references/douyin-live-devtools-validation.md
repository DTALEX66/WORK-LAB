# 抖音小游戏：同步到已打开工程并原地验收

适用于源码仓库生成 `douyin-minigame/`，但开发者工具当前打开的是其本地子工程/副本的情况。

## 行为原则

1. 用户已打开开发者工具时，不另启、关闭或重启工具；先确认窗口标题和当前项目路径。
2. 先在正式源目录执行构建与 strict 检查，再同步确定性产物到当前窗口对应目录。
3. 只覆盖生成项（`game.js`、`game.json`、`project.config.json`、`audio/`、`visual/`）；保留当前工程独有的 workspace 文件和图标。复制后用 SHA-256/数量核对。
4. 在同一窗口触发编译或等待文件监听编译，检查模拟器、Console 错误/警告、首屏、首班交互和素材加载。
5. 自动化点击耗时可能让 60 秒倒计时超时；截图/视觉分析期间应暂停游戏，或用快速脚本连续点击与捕获，不能把自动化超时误报为玩法缺陷。
6. 原地验证产物属于 ignored 本地副本，不要误提交；正式提交仍是源代码、测试和 tracked 平台 bundle。

## CCTV 宽图适配竖屏监控区

- 720×420 横图进入接近竖向的 Canvas 区域时，`cover` 会裁掉左右电梯主体。
- 玩家要求完整看到轿厢和左右边界时，前景必须按 `contain` 等比绘制。
- 为避免上下纯黑死区，可先以约 0.2 透明度绘制同图 `cover` 作为环境底层，再叠加完整 `contain` 前景。
- 运行时 HUD、楼层、状态和异常叠层继续覆盖在最上层；禁止恢复图片内烘焙文字。
- 回归测试应禁止 CCTV 主绘制函数退回 cover-only，并在官方模拟器截图中检查主体完整性。

## Windows 后台验收技巧

- 优先使用 Computer Use 按元素操作。
- Electron 工具可用远程调试端口读取 Console/DOM；窗口截图可用 `PrintWindow`，避免抢前台。
- 若窗口已最小化，不擅自恢复或置顶；完成文件同步和测试后让用户自行恢复查看。
- 技术降级只能用于当前会话，不要固化“某工具不可用”的负面结论。
