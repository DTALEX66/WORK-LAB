# 多源交叉对比脚本

当课程同时有 PDF 文档和 ASR 视频转写时使用。
分析两种源的术语重叠率，标注互补关系。

## 用法

```bash
python tmp/cross_all.py
```

## 核心逻辑

1. 扫描 `10_课程库/*/C*/03_逐节总结/` 目录
2. 分组：PDF文件（不含"ASR"）vs ASR文件（含"ASR"）
3. 提取前 3000 字符的 2-6 字中文术语（过滤停用词）
4. 计算交集/并集比率
5. 写入 `06_验证与不确定项.md` 的 `## 多源交叉对比` 区块

## 结论解读

- 重叠率 <10%: 正常——教材讲理论，视频讲实战，互补关系
- 重叠率 >30%: 教材和视频高度重合（稀有）
- 标注为"互补关系"不应标记为错误
