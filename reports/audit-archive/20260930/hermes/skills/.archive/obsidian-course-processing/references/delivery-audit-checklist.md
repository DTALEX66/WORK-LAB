# 100% 交付审计与批量后处理清单

## 审计表模板

每门课程 `00_课程主页.md` 末尾加：

```markdown
## 完成度审计

| 维度 | 达成 |
|---|---|
| PDF文本 | Y/N/N/A |
| ASR转写 | Y/N/N/A |
| 视觉索引 | Y |
| 外部链接 | Y |
| 内部导航 | Y |
| Dataview | Y |
| 验证页 | Y |

**完成度: 100%** ✅
```

## N/A 规则

- 素材型课程（C0409 软件、C0411 图片）：PDF/ASR 都 N/A
- 视频为主课程：ASR 评估 Y/N，PDF N/A
- 古籍/纯文本课程：ASR N/A，PDF OCR Y/N

## 批量后处理清单（7 项）

做完管道后执行一次完成：

1. 分类首页 — 每个 `10_课程库/<cat>/00_<cat>首页.md`，含 wikilink 列表 + Dataview
2. 外部链接 — 每门课程添加权威参考链接（adobe.com/apa.org/wikipedia.org 等）
3. 验证页 — `06_验证与不确定项.md` 填入提取来源（pymupdf/SenseVoice/PaddleOCR）
4. 视觉索引 — `12_视觉索引与配图.md` 至少占位文件
5. Wikilinks — 每门课链接到分类首页 + 课程总览
6. Dataview — 每门课底部添加 `dataview` 查询
7. 完成度审计 — 计算分数，全部 100% 后标记 ✅

## 补丁循环

```
检测所有 N → 逐个修复 → 重新审计 → 批量提交
```

不要一条条提交，一次性提交全部修复。
