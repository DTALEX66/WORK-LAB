# Board — 紧凑 HUD 视觉方向（锁定板）

- **生成时间**：2026-10-19
- **性质**：**不是**从零发散 3–4 套方向。配色与圆角已被
  `apps/observer/frontend/DESIGN.md` 固定，且亮色环的地板值经过 AA 实测修正；
  本轮做的是「把已有方向固化成可复用板 + 一次被否决的替代研究」。
- **方向名**：Control-plane glass / 控制台玻璃

## 1. 色彩

### 暗色（默认）

| Token | 值 | 用途 | 实测 |
| --- | --- | --- | --- |
| canvas / surface | `#050D16` / `#081420` | 浮窗底、面板 | — |
| surface2 | `#0C1B2A` | notch、次级面 | — |
| text | `rgb(238,246,252)` | hero 总量 | — |
| muted | `#8EABBC` | 标签、注 | 12px |
| primary | `#2A91FF` | 环 1、辉光 | `rgb(42,145,255)` |
| secondary | `#20CDE1` | 环 2、spark 末段 | `rgb(32,205,225)` |
| accent-3 | `color-mix(primary 52%, secondary)` | 环 3 | `color(srgb .1459 .6816 .9435)` |
| success / warning / error | `#22C55E` / `#F59E0B` / `#EF4444` | 状态点 | 只表达状态，不表达动作 |

### 亮色

| Token | 值 | 用途 | 对比度 |
| --- | --- | --- | --- |
| bg / surface / surface2 | `#F4F7FA` / `#FFFFFF` / `#EAF0F6` | 底、卡片 | — |
| text / muted | `#0B1420` / `#4A6172` | 正文 | AA |
| primary / primary-text | `#1B7FE6` / `#1565C0` | 环 1、链接 | AA |
| **hud accent-2** | `rgb(11,95,107)`（`--secondary-ink-rgb`） | 环 2、spark 末段 | **7.33:1** |
| hud accent-3 | `color-mix(primary-text 52%, ink)` | 环 3 | ~6.49:1 |

> **被否决的替代**：亮色继续用霓虹青 `#20CDE1`。实测白底 1.93:1、surface2 1.68:1，
> 低于非文本图形 3:1 的地板。改用 ink 青后达到 7.33:1，且不改变暗色观感。
> 这是"新配色不覆盖既有配色"规则的一个正面例子：暗色保持默认，亮色只替换不安全的值。

## 2. 字体与数字

| 层级 | 字号 | 说明 |
| --- | --- | --- |
| hero 总量 | 41.8px（baseline） | tabular numerals；18 字符时降到 23.3px，最小 22px |
| facts / 卡片总量 | 16px / 12px | 12px 为可读地板 |
| 标签 / 注 | 12px | 不允许更小（实测 `tinyText: []`） |

数字格式规则：
- `<10,000` 用精确分组（`700` 不是 `1k`——四舍五入会虚增 43%）。
- `null` → `UNKNOWN`，`0` → `0`（真实零），份额 0/0 → `—`。
- 部分分母 → `≥` 前缀。

## 3. 形状与材质

| 元素 | 规格 |
| --- | --- |
| 面板圆角 | `--radius: 18px` |
| 内部卡片 | `--radius-sm: 12px` |
| notch | 165×26，下圆角 14px，顶部辉光 2px + 34px 模糊晕 |
| 玻璃 | 径向高光（primary 12%）+ 顶部 2% 白 / 底部 2% 黑 |
| 阴影 | `--shadow-soft` + inset 1px 白 5% |
| 聚合卡 | 虚线边框（`data-aggregate`），区别于真实来源 |

> 已知实现债：notch 的 `rgba(0,0,0,.3)` 与面板 inset 的 `rgba(255,255,255,.05)`
> 还是裸值（CHK-03），下一轮 token 化。

## 4. 状态色语义

| 状态 | 颜色 | 形状 / 文案 |
| --- | --- | --- |
| LIVE | success 绿 | 脉冲点（reduced-motion 关闭）+ 文案 `LIVE` |
| LIVE + stale | warning 琥珀 | `data-state=waiting` + `LIVE · 采样已过期` |
| UNVERIFIED | muted | 不脉冲，不冒充 LIVE |
| OFFLINE | error 红 | 静态点 + 保留上次快照 |
| 零份额 | muted | 环用 butt 端帽，零长度不画点 |

**红线**：颜色永远不单独承载语义——每个状态都有文案 + `data-state`。

## 5. 动效

| 元素 | 时长 / 曲线 | reduced-motion |
| --- | --- | --- |
| 状态点脉冲 | 2.4s ease-in-out infinite | 关闭 |
| 卡片抬升 | .18s ease | 关闭 |
| 环弧 | .4s ease | 关闭 |
| 眼睛跟随 | .08s linear | 关闭 |

不做无限背景动效、不做大位移；HUD 是常驻表面，动效只用于状态与指针反馈。

## 6. Do / Don't

- ✅ 用一个强调色讲一个状态；用 `≥` / `UNKNOWN` 讲不确定性。
- ✅ 亮色先量对比度再选色；暗色保持既有默认值。
- ✅ 聚合卡必须看起来像聚合（虚线 + "其他 n 个来源"）。
- ❌ 不新增第二个主按钮；HUD 没有主操作。
- ❌ 不用霓虹青做亮色图形；不用红/绿表达"可执行"。
- ❌ 不为不存在的按桶历史画热力图或堆叠条。

## 7. 交付物

- 本板 + `design tokens` 现状（DESIGN.md 为准）；**不生成新的 tokens 文件**，避免与
  `l10b-shell.css` / `index.css` 的既有变量形成第二真值。
- 下一轮若做 CHK-03，只新增 `--hud-shadow-notch` 一个变量，并在暗/亮各给一个值。
