# Flow Web — WORK-LAB Observer 紧凑 HUD 的 IA 与状态流

- **生成时间**：2026-10-19
- **范围**：`?view=compact`（440×680）与其出口「完整」视图之间的流；不做移动端（契约外）
- **性质**：现状文档 + 下一轮候选，不含代码变更

## 1. 入口契约

| 入口 | 解析 | 位置 |
| --- | --- | --- |
| `?view=compact` | 旧 Tauri 入口，作为 layout 别名 → 紧凑 HUD | `App.tsx:96-101` |
| `?layout=full\|compact` | 显式布局 | `App.tsx:94` |
| 顶栏「完整 / 紧凑」 | 运行时切换，不刷新 | `TopStatusBar.tsx:148-150` |
| Ctrl K | 命令面板（含 `nav-*` / `act-*`） | `App.tsx:188-219` |
| 主题 | `?theme=` / 切换按钮；**不使用 web storage** | `App.tsx:198` |

状态只走 URL，不落浏览器存储——这是既有契约，新增流不得破坏。

## 3. 主流程

```
S-1 瞥视（默认）
   └─ 读 hero 总量 ──► S-2 判断新鲜度
                         ├─ LIVE ─────────────► 可信，可继续
                         ├─ LIVE · 采样已过期 ─► 数值仍是最近真值，但不可引用为"当前"
                         ├─ UNVERIFIED ────────► 数据到了，但来源未验证
                         └─ OFFLINE / 未接入 ──► 空态，不预填、不写 0
S-2 ──► S-3 定位来源
          ├─ ≤3 源：直接读环与份额
          └─ >3 源：聚合卡 + "明细见顶栏「完整」"
S-3 ──► S-4 切换完整视图（布局切换 / Ctrl K）
          └─ 核对项目行、覆盖口径、来源 ref
S-4 ──► S-5 返回工作（零动作收尾，无确认弹窗）
```

## 4. 状态矩阵（紧凑视图）

| 维度 | 状态 | 表现 | 出口 |
| --- | --- | --- | --- |
| transport | LIVE | 绿点脉冲（reduced-motion 关闭） | 继续 |
| transport | LIVE + stale | 琥珀、`LIVE · 采样已过期`、`data-state=waiting` | 继续但降级引用 |
| transport | UNVERIFIED | 灰/中性、不冒充 LIVE | 可看数值，需核对来源 |
| transport | OFFLINE | 红点、保留上次快照 + 覆盖/项目数 | 等待 / 打开完整视图 |
| data | 无快照 | hero `UNKNOWN` + "数据源未接入" | 不预填 |
| data | 无来源 | 不画空环，空态文案 | 完整视图 |
| data | 全零 | 显示真实 `0`；份额 `—`（不做 0/0） | — |
| data | 部分未知 | 份额带 `≥`，注"未计入分母" | — |
| data | >3 源 | 前 2 + 聚合卡（虚线） | 完整视图 |
| series | <2 修订 | "序列未形成"空态 | 不补点 |

## 5. 与完整视图的边界

- **紧凑**：瞥视 + 可信度判断；只读；不引入筛选、分段、热力图。
- **完整**：调查与审计；保留 rail、各 lane 与命令面板；密度归它。
- 切换是**同一页面内的布局切换**，不丢 URL 状态；从紧凑切到完整不应重置主题或筛选。
