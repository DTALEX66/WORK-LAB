# Poster — 边界说明（本轮不生成营销海报）

- **生成时间**：2026-10-19
- **结论**：**不生成海报**。这是有意的范围决定，不是遗漏。

## 1. 为什么不生成

1. **产品定位冲突**：WORK-LAB Observer 是内部只读控制面（control plane），
   不是面向外部用户的营销产品；没有发布渠道、没有受众、没有转化目标。
2. **契约冲突**：本仓的视觉契约要求 HUD 不出现动作面、假精确和营销话术；
   海报天然是"主张 + 装饰"的媒介，容易把 `UNKNOWN` / `≥` / 采样过期这类
   真值语言压扁成一句口号。
3. **证据约束**：海报需要可公开的数字与背书；本轮能引用的只有内部实测
   （440×680、617px 内容、7.33:1 等），把它们做成营销数字会脱离口径。

## 2. 如果 owner 明确要一个"对外可见"的产物

唯一不冲突的形态是**仓库内 README 的 hero 图**（不是产品 UI、不是投放物料），
且必须满足：

- 只使用真实实测数字，并带 `rev` / 日期 / 来源；
- 不出现 Allow/Deny 等动作暗示；
- 使用既有暗/亮 token，不新增霓虹青；
- 尺寸 16:9 或 3:2，不伪造设备边框或用户评价。

满足以上条件后，可用 ImageGen 生成一张概念图；否则保持"无海报"。

## 3. 与其它技能的关系

- 对外讲"做了什么"：用 `pitch-20261019.md`（决策叙事），不是海报。
- 对外讲"长什么样"：用 `journey-20261019.html` 与真实截图，不是海报。
- 本轮不产生 `poster` 图片、不占用 `reports/product-design/` 的图片位。
